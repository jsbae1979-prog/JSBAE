# AI 고품질 제작 안내 (선택 기능)

NewsFlow AI의 영상은 두 가지 모드로 만들 수 있습니다. 화면의 시각은 모두 한국 시간(KST)입니다.

| 모드 | 무엇을 하나요 | 비용 | 언제 쓰나요 |
| --- | --- | --- | --- |
| **기본 모드 · 로컬 FFmpeg** | 이 PC의 FFmpeg로 장면마다 카드(제목·자막·출처)나 내 이미지로 영상을 만듭니다. 외부 영상 API를 쓰지 않습니다. | 없음 | 언제나. 설치 직후 기본값 |
| **AI 고품질 모드** | 고른 장면만 외부 AI 영상 공급사(Higgsfield)에서 배경 영상을 만들고, 같은 FFmpeg로 자막·음성·출처를 얹어 합성합니다. | 유료(공급사 요금) | 승인·한도·모델·API 키를 모두 준비했을 때 |

AI 고품질 모드는 처음에 꺼져 있습니다. 꺼져 있어도 기본 모드는 똑같이 동작합니다.

## 1. 시작 전에 확인할 것

AI 영상 생성은 유료이며 실패해도 비용이 생길 수 있습니다. 아래 항목은 이 앱이 공식 문서를 열지 못해 확인하지 못한 내용(NOT VERIFIED)이므로 **직접 Higgsfield 공식 문서와 대시보드에서 확인**하세요. 자세한 근거는 [Higgsfield API 검증 결과](reports/phase5d_higgsfield_api_verification.md)에 있습니다.

1. API 키 발급 위치와 형식(공식 안내: open.higgsfield.ai의 API Keys 화면에서 복사).
2. 쓰려는 모델의 경로(예: `kling-video/v2.6/pro/text-to-video`), 허용 길이(초), 세로 9:16·해상도 지원 여부, 초당 가격.
3. 잔액 충전 방법, 실패·정책 거부·취소 요청의 청구·환불 규칙.
4. 결과 파일 보관 기간, 동시 요청 한도, 상업적 이용·AI 생성 고지에 관한 이용약관.

## 2. 설정하기 (`설정` → `AI 영상(선택)·모델·비용 한도 →`, 주소 `/video-ai-settings`)

1. **AI 영상 공급사**를 `Higgsfield (유료 · 승인 필요)`로 고릅니다.
2. **작업별 한도**와 **월 한도**를 입력합니다(USD 또는 KRW). 작업별 한도는 영상 계획 하나에 쓸 수 있는 최대 금액이고, 월 한도는 매월 1일 한국 시간 오전 9시(UTC 0시)에 새로 계산됩니다. 대본용 OpenAI 토큰 한도와 따로 관리합니다.
3. 유료 생성 승인 문장에 체크하고 저장합니다. 한도가 없으면 승인이 저장되지 않습니다.
4. **모델 추가**에서 공식 문서로 확인한 모델 경로·표시 이름·초당 단가·허용 길이(예: `5,10`)·해상도를 넣고, "공식 문서와 대시보드에서 직접 확인했습니다"에 체크합니다. 체크와 단가가 있는 모델만 쓸 수 있습니다.
5. **API 키**를 붙여 넣고 저장합니다. 키는 이 PC의 Windows 계정 보호 저장소(DPAPI)에 OpenAI 키와 다른 파일로 암호화되어 저장되며 화면·데이터베이스·로그에 다시 나타나지 않습니다.

"지금 상태"에 `AI 영상 사용 가능`이 보이면 준비가 끝난 것입니다. 사용 불가이면 그 이유가 함께 표시됩니다.

## 3. 영상 만들기 (`고급 모드` → `Video Studio` → `AI 고품질 제작 (선택) →`, 주소 `/video/ai`)

1. **새 AI 영상 계획**에서 검토한 대본과 길이(30·45·60초)를 고르고 `스토리보드 만들기`를 누릅니다. 장면 나누기·시간·내레이션·자막은 기본 모드와 똑같으며, 처음에는 모든 장면이 기본 카드입니다.
2. **스토리보드**에서 장면마다 소재를 고릅니다.
   - `기본 카드` — 외부 호출 없음.
   - `로컬 이미지` — assets 폴더의 내 이미지(사용 권리 확인 체크 필요).
   - `AI 생성 영상 (유료)` — 프롬프트(600자 이내)와 모델을 고릅니다. 실제 사건 현장·기록 영상·CCTV·실존 인물·딥페이크처럼 보이게 하는 표현, 인터넷 주소·이메일은 거부됩니다. 모든 프롬프트 끝에는 "추상 일러스트이며 실사·뉴스 영상이 아니고 실존 인물·얼굴·장소·로고·문자가 없다"는 영어 문장이 자동으로 붙습니다.
3. **예상 비용 확인과 유료 생성**에서 장면별 예상 비용(모델 설정에 지금 저장된 단가·허용 길이로 계산)과 합계, 이 작업·이번 달 사용액과 한도를 확인한 뒤 체크하고 `유료 생성 요청`을 누릅니다. 이때 한도를 넘거나 체험(합성) 뉴스 대본이면 거부됩니다.
4. 장면 상태가 `제출 대기 → 공급사 대기열 → 생성 중 → 내려받는 중 → 생성 완료`로 바뀝니다. 제출 대기 중에 승인을 해제하거나 공급사·한도·모델 단가를 바꾸면 그 장면은 보내지 않고 취소되며(비용 없음), 승인을 다시 저장해도 이전 확인으로는 보내지 않으니 예상 비용을 다시 확인하세요. 화면은 3초마다 상태를 확인합니다. 프로그램을 닫았다 열어도 이미 보낸 요청은 다시 보내지 않고 상태만 이어서 확인합니다.
5. **원본 뉴스와 AI 생성 장면의 관계 검토**에서 각 AI 장면 미리보기를 보고 "추상적 연출 화면이며 실제 현장·인물로 오인될 표현이 없다"에 체크하고, 표시·자막·출처 확인 문장에 체크해 저장합니다.
6. **최종 합성 승인**에 체크하고 `최종 합성 시작`을 누르면 기본 모드와 같은 FFmpeg 경로로 MP4를 만들고 영상 작업 화면으로 이동합니다.

최종 영상의 모든 AI 장면에는 끌 수 없는 노란 표시 **AI 생성 장면 · 실제 현장 영상 아님**이 들어갑니다. 영상 작업 화면과 `제작 영상` 보관함에도 "AI 생성 장면 포함"이 표시되며, 게시 준비에서는 AI 생성 표시(`disclose`)를 골라야만 검사를 통과합니다.

## 4. 문제가 생겼을 때

| 화면 표시 | 뜻과 할 일 |
| --- | --- |
| 실패 · 정책 거부 | 공급사가 생성을 거부했거나 실패했습니다. 프롬프트를 바꿔 다시 생성하거나 카드·로컬 이미지로 바꾸세요. 비용은 보수적으로 사용액에 남습니다. |
| 결과 불명 | 요청을 보낸 뒤 연결이 끊겨 결과를 모릅니다. 이중 청구를 막기 위해 자동으로 다시 보내지 않고, 이 장면은 잠깁니다. 공급사 대시보드를 확인한 뒤 `결과 불명을 실패로 확정`을 누르면 수정하거나 다시 생성할 수 있습니다. |
| 결과 다시 받기 | 생성은 끝났지만 내려받기·검증·디스크 공간 문제로 받지 못했거나, 장면별 제한시간이 지나 닫혔습니다(공급사가 취소를 받아들인 경우는 '취소'로 닫혀 받을 결과가 없습니다). 추가 생성 요청 없이 같은 요청의 결과를 다시 확인해 받을 수 있습니다(받기에 3번 실패하면 끝, 디스크 공간 부족은 세지 않음). 다시 받을 수 있는 동안 이 장면은 다음 유료 생성 묶음에 들어가지 않으며, 다시 생성하려면 그 장면의 `받아 둔 유료 AI 영상 버리기`에 체크하고 프롬프트나 모델을 바꾸세요. 3번 모두 실패하면 다음 유료 생성 확인 때 이 장면도 새로 생성되어 비용이 다시 듭니다(비용 화면에 안내됨). 원하지 않으면 카드로 바꾸세요. |
| 생성 취소 | 제출 전이나 공급사 대기열에 있을 때만 취소할 수 있습니다. 생성이 시작된 요청은 취소할 수 없습니다. |
| 받아 둔 영상 파일이 없거나 바뀜 | 최종 합성 승인 때 발견하면 그 장면을 '결과 다시 받기' 가능 상태로 바꿉니다(합성을 이미 마친 계획과 오래된 화면에서 누른 승인은 아무것도 바꾸지 않습니다). 공급사에 결과가 더 없거나 다시 받기를 3번 모두 쓴 장면은 다시 받을 수 없으므로 거부 문장대로 카드로 바꾸거나 다시 생성하세요(비용 화면에 따로 안내). 다시 받거나, `받아 둔 유료 AI 영상 버리기`에 체크한 뒤 카드로 바꾸세요(데이터 폴더를 옮길 때 `ai-clips`를 빠뜨린 경우 등). |
| 최종 합성 실패 | 받아 둔 AI 영상은 그대로 있습니다. 장면을 고치거나 `최종 합성 다시 시작`을 누르세요(추가 생성 비용 없음). |
| 생성 영상 파일을 지금 읽을 수 없음 | 다른 프로그램(동영상 플레이어·백신 검사 등)이 파일을 열고 있거나 파일 권한이 맞지 않습니다. 닫은 뒤 다시 합성 승인을 누르세요. 계속 읽을 수 없으면 화면을 새로 고쳐 그 장면에 `결과 다시 받기`가 나타나면 그것으로 새로 받으세요(추가 생성 요청 없음, 최대 3번). 공급사에 결과가 더 없거나 다시 받기를 3번 모두 쓴 장면은 이 버튼이 나타나지 않고 거부 문장이 버리기를 안내합니다. 이때는 프로그램을 닫거나 권한을 확인한 뒤 다시 승인하고, 계속 읽을 수 없으면 `받아 둔 유료 AI 영상 버리기`에 체크한 뒤 카드로 바꾸세요(새로 생성하면 비용이 다시 듭니다). 파일이 다시 읽히면 받지 않고 승인을 다시 누르라고 알려 줍니다. |
| 새 파일을 받지 못해 원래 생성 영상을 그대로 둡니다 | 읽을 수 없던 영상을 다시 받으려 했지만 받지 못했습니다. 원래 영상은 '생성 완료' 그대로 남습니다. 파일을 읽을 수 있게 한 뒤 관계 검토를 다시 하고 승인하세요. 디스크 공간 부족 안내가 함께 나오면 공간을 확보한 뒤 `결과 다시 받기`를 다시 누르세요(횟수에 세지 않음). "더 이상 다시 받을 수 없으니"가 붙으면(공급사에 결과가 없거나 3번 모두 실패) `결과 다시 받기`는 더 나타나지 않으니, 계속 읽을 수 없을 때는 `받아 둔 유료 AI 영상 버리기`에 체크한 뒤 카드로 바꾸세요. |
| 파일이 없거나 바뀌었고 공급사에도 결과가 더 없습니다 | 다시 받을 방법이 없습니다. 카드로 바꾸거나 다시 생성하세요. 다시 생성하면 비용이 다시 들며 비용 화면에 따로 안내됩니다. |
| AI 생성 영상을 아직 받지 못했습니다 | 합성 승인 때 받지 못한 유료 결과가 있는 장면입니다. 그 장면의 `결과 다시 받기`로 받거나, `받아 둔 유료 AI 영상 버리기`에 체크한 뒤 카드로 바꾸세요. |
| 받아 둔 영상이 버려집니다 | 생성 완료(또는 다시 받기 가능) 장면의 소재·프롬프트·모델을 바꾸려 했습니다. 정말 바꾸려면 그 장면의 `받아 둔 유료 AI 영상 버리기`에 체크하고 저장하세요. 버린 영상은 다시 쓸 수 없고 새로 생성하면 비용이 다시 듭니다. |
| 모델 옆 "(현재 사용 불가)" | 장면에 쓴 모델의 확인·단가가 해제되었습니다. 이미 받아 둔 영상은 그대로 합성할 수 있고, 새로 생성하려면 다른 모델을 고르세요(받아 둔 영상이 있는 장면은 `받아 둔 유료 AI 영상 버리기` 체크 필요). |
| 대본이 바뀌었습니다 | 계획을 만든 뒤 대본을 고쳤습니다. 장면 수와 장면 시간이 같으면 `바뀐 대본 반영`을 눌러 받아 둔 AI 영상은 그대로 두고 내레이션·자막만 반영한 뒤 관계 검토를 다시 하세요. 장면 구성이 바뀌었으면 새 계획을 만드세요. |
| 통화가 바뀌어 이 계획에는 더 생성할 수 없습니다 | 이 계획의 이전 사용액이 다른 통화로 기록되어 있어 한도를 계산할 수 없습니다. 비용 화면의 "이 작업 누적"은 지금 통화의 사용액만 보여 줍니다("(다른 통화 사용액 제외)"). 새 계획을 만드세요. |

## 5. 알아 둘 점

- 예상 비용은 설정에 입력한 초당 단가로 계산한 참고값입니다. 실제 청구는 공급사 대시보드에서 확인하세요.
- 받은 AI 영상은 데이터 폴더의 `ai-clips`에 보관됩니다. 데이터 폴더를 다른 곳으로 옮길 때는 `ai-clips` 폴더와 `video-ai-key.dpapi`도 함께 복사하세요(이전 도구는 데이터베이스와 세션 키만 복사합니다).
- 자동 제작(간편 제작)은 계속 기본 카드 영상만 만듭니다. AI 고품질 모드는 영상 제작 화면에서만 씁니다.
- 생성 영상의 품질과 실제 공급사 동작은 사람이 확인해야 하는 항목입니다(NOT VERIFIED).

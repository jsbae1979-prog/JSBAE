# 라이브러리 복수 선택 · 콘텐츠 삭제

기존 라이브러리는 미리보기 카드 1개 선택만 지원했고 뉴스 영상에만 파일 휴지 보관 명령이 있었다. 캐릭터 작업·이미지·게시 이미지·사용자 보관 참조에는 공통 라이브러리 삭제 동작이 없었다.

이번 변경은 카드 체크박스, 현재 표시 항목 전체 선택, 선택 해제, 선택 수량, 선택 삭제와 단일 콘텐츠 삭제를 제공한다. 카드 미리보기·제작실 이동과 삭제 선택은 구분한다. 검색·필터 변경 시 선택을 초기화한다. 삭제 전 항목과 수량을 확인하며, 라이브러리 휴지 보관에서 복원할 수 있다.

삭제는 현재 사용자 DB의 기존 WorkspaceRemoval 저장 구조를 이용한 라이브러리 목록 보관 처리다. 원본 프로젝트·영상·이미지·캐릭터 등록·공급사 요청/비용/승인 이력은 지우거나 이동하지 않는다. 다른 제작실과 기존 작업 이력의 저장 자료도 유지한다. 다른 사용자 자료나 임의 파일 경로는 삭제 대상으로 받지 않는다. DB migration은 추가하지 않는다.

기존 인증·Origin·CSRF 검사와 운영 로컬 쓰기 경계를 유지한다. 새 로컬 삭제·복원 경로만 등록하며, 생성·게시·업데이트 권한은 추가하지 않는다. 여러 항목은 전체 검증 후 한 번의 트랜잭션으로 처리한다. 진행 중인 항목 등 처리할 수 없는 대상이 섞이면 일부만 삭제하지 않고 전부 보존한다. 응답 불명·실패 시 자동 재요청하지 않는다.

합성 데이터와 외부 통신 차단 브라우저로 검증한다. 운영 콘텐츠를 실제로 삭제·복원하거나 유료 API를 실행하지 않는다. 코드 반영을 위한 추가 정상 Stop·Start는 별도 사용자 승인 전까지 수행하지 않는다.

정확한 테스트 결과·파일 목록·코드 SHA·운영 적용 상태는 최종 검증 뒤 아래에 기록한다.

## 검증 및 적용 상태

브라우저 첫 시도의 합성 데이터 준비 4 ERROR는 대본 전 작업에 prompts를 넣지 않은 테스트 fixture 오류였다. 두 번째 4 FAIL은 라이브러리가 사용하는 작업 주제를 대본 제목으로 잘못 가정한 테스트 선택자 문제였다. fixture만 수정한 뒤 해당 신규 4개가 모두 통과했다. 제품 코드를 바꿔 시험을 우회하지 않았으며 처음 성공한 기존 1개는 반복하지 않았다. 기존 전체 회귀·Guard 감사·패키징은 반복하지 않았다.

## 운영 반영 완료

사용자가 라이브러리 수정본 운영 반영 및 정상 Stop·Start 1회를 승인했다. 준비된 코드 `531958cd2e3a0c0f32eaec500b985f56f36c7120`의 7개 파일을 반영했다. 정상 Stop 1회/종료 코드 0, Start 1회. 새 PID는 9196, 주소는 127.0.0.1:18768이다. 기존 런처의 정상 인증 경로로 Chrome 자동 열기를 확인했다. 무인증 GUI HTTP는 기존 보호대로 403을 반환하며, 인증 우회나 토큰 출력은 하지 않았다. 사용자 Chrome의 실제 다중 선택 화면은 아래 사용자 확인으로 정상 표시가 확인됐다.

전환 직전 프로필 백업 126개를 보존했다. 정상 인증용 세션 파일 등을 제외한 125개 파일, DB 47개 테이블/기사 169건, 원본 및 백업 A/B, 실행 설정과 보안 플래그가 보존됐다. 캐릭터 작업 백업 27개에서 실제 진행·합성·제출·다운로드 중인 작업과 장면은 각각 0개였다. 배포 helper의 기존 사전 확인에 빠졌던 composing/retry_quoting 및 하위 장면 상태도 향후 적용을 위해 보완했다. 이 보완 때문에 추가 Stop/Start를 하지 않았다.

운영 콘텐츠 삭제·복원, API 연결 확인·유료 생성·SNS 호출은 모두 0회다. 기존 사용자 데이터나 원본 파일을 시험용으로 삭제하지 않았다. 이전 운영 반영 승인 대기 표기는 이번 완료 기록으로 대체된다.


## 사용자 Chrome 최종 확인

2026-10-30 (Asia/Seoul), 사용자가 “다중 선택·삭제·휴지통 모두 정상 표시”라고 확인했다. 인증된 운영 Chrome에서 선택 기능과 삭제·휴지통 UI 표시가 확인됐으며, 실제 운영 콘텐츠 삭제·복원을 실행했다고 확대 해석하지 않는다. 해당 기능의 삭제·복원 동작은 앞서 통과한 합성 검사 결과를 사용한다.

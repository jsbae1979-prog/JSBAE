# 장면 자동 진행 및 최종 합성 표시 보정

승인된 영상 작업은 화면을 열어 둔 동안 10초마다 기존 인증된 상태 확인 경로를 이용합니다. 생성 완료 결과 저장과 기존 승인 범위의 연속 장면 연결은 서버의 기존 계약을 재사용합니다. 장면마다 클릭할 필요가 없습니다.

완료 장면 수, 저장 기준 진행률, 생성·저장·검토·최종 합성 상태를 표시합니다. 실패·결과 불명·통신 오류는 자동 확인을 중단하며 유료 재생성이나 자동 재시도를 수행하지 않습니다. 최종 합성은 장면 검토 후 별도 실행합니다.

사용자가 요청한 자막·코믹 효과음·기존 환경음 연결은 현재 운영 Python을 유지해 사용합니다. 새 나레이션은 넣지 않습니다. 직전 무자막 합성 패치는 운영 미적용 상태에서 철회했습니다.

신규 집중 검증: Fake 브라우저 6 PASS, 기존 영향 범위 Node 10 PASS, TypeScript 및 React 빌드 PASS. 1366×768 / 1920×1080 캡처는 합성 환경입니다. 실제 유료 생성으로 자동 진행을 새로 시험하지 않았습니다. 운영 재시작은 수행하지 않습니다.

# NewsFlow AI development rules

- Phase 5C real-content production (registered public RSS, gated external AI with stored approval and monthly token limit, Windows Korean SAPI voices, audio-fit subtitles, mandatory script/final reviews) is authorized. No scheduler development. Reuse the collection, intelligence, video and publishing services, preserve approval boundaries, and keep actual OAuth and SNS execution hard blocked. Do not log in to real SNS accounts, exchange real codes/tokens, store or load real service credentials, upload/publish, begin Phase 4B-2C or Phase 5B scheduling, or merge main. Environment variables and GUI approval flags cannot enable production OAuth. Preserve the existing synthetic-only vault and migrations 0001–0009; add new migrations for later phases. External AI runs only for real-content jobs whose settings gate (provider, dated approval, monthly limit, key) passes; trial jobs never leave the machine. The AI key lives in the DPAPI key store or the environment, never in SQLite, logs or templates. Phase 5C.1 operational readiness is authorized: public feed review tooling through the unchanged adapter policy, token/cost estimates from user-entered unit prices (display only; the monthly token limit stays the gate), Korean voice registry detection and speech-text normalization for the synthesizer only, a human listening record that is never set by automation, the opt-in single live AI check (NEWSFLOW_AI_LIVE_TEST=1 plus the stored gate), and the Phase 5D Higgsfield design document only (no Higgsfield API or MCP call). Phase 5C.1 adds no migration. Phase 5D optional AI video is authorized: a vendor-neutral `VideoProvider` with a Higgsfield REST provider that never retries a submit and an injected, test-only Fake provider. It is off by default and sends a scene only after a dated approval, per-job and monthly cost limits kept separate from the OpenAI token limit, a user-confirmed model with a per-second price, a key in its own DPAPI store (`video-ai-key.dpapi`) or `NEWSFLOW_VIDEO_AI_KEY`, and a per-plan paid confirmation. Generated scenes carry the fixed AI label, need a relation review and a separate compose approval, and are composed through the existing FFmpeg path; the basic FFmpeg mode never calls an external video API and Autopilot stays card-only. Development, tests and CI never call the real Higgsfield API or any Higgsfield MCP tool; a real paid call happens only on the user PC after the user's own approval. Migrations 0010 and 0011 are additive; preserve 0001–0011 (never edit a published revision; add a new one).
- Python 3.12; production target is Windows 11 only. Codex Cloud is for development/tests; no Linux deployment, Docker, or WSL features.
- Keep GUI, services, persistence, and external adapters separate.
- Never commit API keys, OAuth tokens, personal data, local databases, or session secrets.
- No article body scraping, login/paywall bypass, or actual SNS publishing.
- Default to fixture/fake-adapter tests. Live RSS tests must be opt-in.
- Preserve unknown publication dates and unassessed score components.
- Run `python -m pytest -q -rs`; distinguish tests from real network/browser/OS validation.
- Every cloud task is already isolated. Use this checkout; do not create a worktree unless requested.

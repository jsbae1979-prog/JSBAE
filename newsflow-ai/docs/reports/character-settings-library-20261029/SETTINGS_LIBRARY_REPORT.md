# 캐릭터 영상 길이·화질·내 캐릭터 저장 수정

2026-10-29. 개발·집중 검증 완료, 이번 변경의 운영 반영과 재시작은 아직 하지 않았다.

## 수정 내용

- 저장 스토리라는 이유로 총길이를 잠그던 UI와 서비스 조건을 수정했다. 새 복사본과 안전한 미제출 작업은 15~60초를 선택하고 5개 장면을 균등 배분한다(30초=6초×5). 스토리 내용과 원본·이미 제출·결과 불명·청구·승인 자료는 바꾸지 않는다. 기존 견적의 원래 스토리·길이·payload는 이력으로 보존하고 다시 견적한다.
- Kling 3.0 Standard는 공식 API에 화질 파라미터가 없으므로 고정 Standard로 표시한다. Kling O3는 공식 `mode` 값 std/pro/4k를 수동 선택하고 요청에 그대로 연결한다. 자동 Pro/4K 상향은 없다. 과거 O3 model_default 저장 자료는 변경하지 않고 실행 시 Standard로 해석한다.
- AI 생성 모드와 최종 로컬 출력 크기를 구분해 표시한다. 최종 출력은 720p·1080p·4K이며, 로컬 확대가 원래 영상의 세부 품질을 늘린다고 주장하지 않는다. Pro/4K 비용과 계정 권한은 실제 공식 견적·생성 전 미확정이다.
- 기본 해제된 ‘내 캐릭터에 저장’ 체크박스를 추가했다. 사용자가 체크할 때만 사용자 프로필의 콘텐츠 주소형 PNG와 캐릭터 목록 정보를 저장한다. 동일 이미지 재등록은 중복 생성·기존 이름 덮어쓰기 없이 처리한다. 미체크는 저장하지 않는다. 내 캐릭터 선택은 검증된 자산 ID를 통해 새 참조로 실제 연결하며, 별도 제작 이력이나 AI 성공 기록을 만들지 않는다.

## 검증

- 길이·안전한 시간 재배분 및 기존 장면 영향: 34 PASS.
- 모델 카탈로그·실제 mode 매핑·과거 O3·출력 크기: 50 PASS. 넓은 HTTP 경로 검사는 테스트 이벤트 루프 준비에서 정체돼 중단했으며, 이 숫자는 완료된 정확한 집중 검사 결과만 뜻한다.
- 내 캐릭터 저장·재열기·중복·프로필 분리·인증/Origin/CSRF·선택 자산 재사용: 10 PASS.
- 통합 TypeScript 검사와 Vite 빌드 PASS. 기존 폰트·모듈/청크 경고가 남아 있다.
- 추가 범용 자산 회귀 10개는 공용 step13_isolation fixture 미등록으로 준비 단계 ERROR다. 제품 검사를 실행한 것으로 세지 않는다. Guard를 바꾸거나 우회해 통과시키지 않았으며, 직접 수정한 자산의 집중 검사 증거를 구분해 보존했다.
- 그룹 간 겹치는 검사가 있을 수 있으므로 위 숫자를 합산한 신규 총계는 제시하지 않는다. 실제 API·생성·SNS·운영 재시작·운영 데이터 변경은 수행하지 않았다.

## 구현
- 정치·경제·사회·IT/과학·문화·연예·스포츠·국제 다중 선택. 빈 선택은 기존 전체 수집.
- 인기 뉴스 공개 RSS와 SerpApi 한국 수집에 적용. 글로벌 수집의 기존 5회 경로는 유지하며 분야 선택은 허용하지 않는다.
- RSS는 기존 공개 Google News 토픽 경로를 사용한다. 정치·문화는 키워드 검색 RSS, IT/과학은 TECHNOLOGY와 SCIENCE 두 RSS를 사용한다.
- SerpApi는 분야별 OR 검색어와 when:1d로 한 요청씩 수행한다. 중복 분야는 제거하고 실제 제출 전 요청 의도를 보존한다. 실패 후 남은 분야는 자동 요청하지 않으며 동일 요청 토큰을 재전송하지 않는다.
- 공식 q 검색 계약 참고: https://serpapi.com/google-news-api . 실제 API 및 RSS 네트워크 요청은 하지 않았다.
- 최근 기간 6/12/24/48시간 및 기본 24시간 필터, 기존 화제성 평가와 lifecycle 정책을 재사용한다. 기존 최근 기사 부족 시 fallback 정책도 그대로 유지한다. 검색의 when:1d는 48시간 전체 수집을 보장하지 않는다.
- 신규 기사에만 선택 분야를 기록한다. 기존 기사의 분야는 변경하지 않는다. 여러 분야 중복 기사는 기존 중복 제거를 사용하며 먼저 처리한 정규 순서 분야를 유지한다.
- 선택 분야별 수집/기간 필터 후 건수와 요청 수를 표시한다. 실제 과금 크레딧은 미확정으로 유지한다.
- 두 actions 레지스트리에 같은 필드를 등록했다. 새 POST 경로는 없다. 기존 인기 RSS POST를 운영 어댑터의 정확한 경로 목록에 연결하되 인증·CSRF·공개 RSS 승인 검사를 유지한다.

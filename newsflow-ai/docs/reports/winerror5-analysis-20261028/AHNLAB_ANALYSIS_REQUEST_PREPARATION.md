## 2. 공식 제출 절차 (향후 별도 승인 후)

1. 안랩 [오진 의심 안내](https://ask.ahnlab.com/hc/ko/articles/900002412366)에서 [위협정보 신고센터](https://www.ahnlab.com/ko/support/virus)로 이동한다. 공식 이용 안내는 로그인 후 신고 유형·제품명·답변 받을 이메일·상세내용을 작성하도록 안내한다. 연락처는 사용자가 자신의 값을 입력하며 GitHub 문서에는 저장하지 않는다.
2. 제품 V3 Lite, 오진 의심/파일 분석에 해당하는 항목을 선택하고 아래 요청문과 최소 증거를 제출 후보로 준비한다. 공식 명칭이 오진 신고여도 실제 결론은 분석 전 미확정임을 명시한다.
3. 공식 접수 안내는 의심 파일을 ZIP으로 첨부하거나 안리포트 arc를 첨부하는 방식 중 적어도 하나를 요구하며 각각2GB 이하로 안내한다. 따라서 **해시·설명만으로 정식 접수가 완료된다고 보장할 수 없다**. 동일 EXE 제출이 필요하면 별도 사용자 승인 후 공식 경로에서만 진행한다. ZIP은 공식 첨부 형식 설명일 뿐 이번에는 생성하지 않았고, 업로드 제한을 우회하기 위해 사용하지 않는다. 보호 해제·격리 복원·파일명 변경·재빌드도 하지 않는다. 암호 규칙 등 추가 요구는 접수 화면/안랩 안내를 따른다. [공식 접수 안내](https://ask.ahnlab.com/hc/ko/articles/900003237626)
4. 원본 실행파일의 바이너리 바이트와 hash를 유지하고 비밀값이 섞인 디렉터리는 첨부하지 않는다. 안리포트가 추가로 요구되면 수집 범위·민감정보·전송 승인을 별도 확인한다.
5. 사용자가 개인정보 동의와 최종 제출을 결정한다. 접수번호·제출 파일 해시·시각·안랩 회신을 별도 보존한다. 공식 안내상 결과는 마이페이지 신고 내역과 이메일로 확인한다. [공식 접수 안내](https://ask.ahnlab.com/hc/ko/articles/900003237626)
6. 회신의 분석 대상 SHA-256, 악성/오진/평판 차단 구분, 권고 조치와 적용 버전을 확인한다. 회신 전 차단 해제·예외·반복 실행은 하지 않는다. 접수 성공을 오탐 확정 또는 실행 성공으로 바꾸지 않는다.

안랩 안내에 개발중 파일의 예외 등록이 언급돼 있어도 이번 사용자 지시는 예외 등록을 금지하므로 해당 방법은 실행 절차에 넣지 않았다. 자동 업로드·이메일 발송·고객지원 메시지 전송도 없다.

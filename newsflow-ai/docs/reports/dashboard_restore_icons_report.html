대시보드 복원과 아이콘 개선

2026-10-24 · 기준 커밋 30a0985에서 변경. 기존 지구본·보관 기사 검색·뉴스/제작/영상 배치를 복원하고 아이콘과 짧은 이름으로 제작 동선을 구분했다.

  • 지구본 헤더와 네이비 디자인, 모든 9개 뉴스 분야 및 보관 기사 검색을 유지했다. 검색은 기존 GET 경로이며 신규 수집이나 AI 검색으로 바꾸지 않았다.
  • 큰 제작 유형 카드 영역을 워크플로 내부의 쇼츠·이미지·캐릭터 아이콘 바로가기로 통합했다. 기존 SVG를 재사용하고 장식 아이콘은 접근성 트리에서 제외했으며 버튼 이름과 키보드 탐색을 유지했다.
  • 제작 단계의 숫자 대신 기능별 아이콘을 표시하고 단계 번호·상태 문구는 스크린리더에 제공한다. 상태와 다음 행동은 기존 저장 기록을 사용한다.
  • 미리보기는 영상 1개만 표시한다. 원래의 영상 확인·MP4 저장·편집·삭제·게시 준비 경로를 유지한다. 이미지 피드와 캐릭터 기록은 제작 현황에서 계속 접근한다.
  • 대시보드의 중복 제작 폼과 동작하지 않는 검토 스위치를 제거했다. 대본 검토 설정은 실제 제작 입력 화면으로 이동하고, 그 화면의 체크박스·유료 사용 동의·자동 검사·최종 검토는 그대로 유지했다.

Chrome 합성 자료로 1440/1100/760/390px 배치·겹침·범주 탭·아이콘 이름·작업별 필터·기록 보존을 확인했다. 외부 요청과 POST는 차단했다. 최초 복원에서 발견한 초안 표시 속성 누락은 수정 후 두 Python에서 해당 검사를 재통과했고, 필터 테스트는 탐색 완료를 기다리도록 수정했다. 실패 테스트를 삭제하거나 skip하지 않았다. 기존 전체 회귀 57 FAIL 기록은 보존하며 이번 결과를 전체 회귀 PASS로 확대하지 않는다.

운영 적용과 보존

활성 예약·진행 중 작업이 없음을 DB의 안정 복사본에서 확인했다. 기존 코드 3개와 DB/WAL/SHM·보호 파일을 영구 백업하고 해시를 확인한 뒤 HTML 2개와 CSS 1개만 반영했다. 운영 앱을 재시작하거나 migration을 실행하지 않았다.

운영 Chrome에서 실제 저장 자료·선택값·9개 분야·아이콘 바로가기 3개·제작 단계 5개·영상 1개·가로 넘침 없음을 확인했다. 이후 복사 DB의 47개 모든 테이블 해시와 키·설정·영상 등 보호 파일 28개 해시가 동일하다. 스키마는 0018이다. 실제 키·토큰은 읽거나 출력하지 않았고, 원본 SQLite에 진단 연결을 열지 않았다.

실제 API·OAuth·음성/영상 생성·업로드·SNS 게시 0회. 공급사 연결·사람의 음질/영상 품질·실제 게시 성공을 검증했다고 주장하지 않는다. 기존 Draft PR #35와 main은 변경하지 않았다.

남은 작업

사용자가 실제 화면의 배치를 확인하는 단계가 남았다. 실제 계정 연결과 공급사 제작·게시 검증은 별도 범위 승인 후 진행한다. 추가 기능이나 새 디자인 개편을 자동으로 시작하지 않는다.

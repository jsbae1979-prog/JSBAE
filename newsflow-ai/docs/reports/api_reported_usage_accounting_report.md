# API 보고 사용량 집계 및 Claude 검색 재검증

2026-10-17. 사용자 승인에 따라 요청별 USD 한도와 추정 사전 예약액으로 차단하던 정책을 제거했다. 공급사 응답의 토큰·검색 사용량과 저장된 단가로 사후 비용을 추정한다. 이는 실제 청구액이 아니며, 한 요청의 최종 금액이나 월 예산 이내 완료를 보장하지 않는다.

## 구현

- 기존 API 요청 원장을 재사용한다. 신규 요청은 `reported_usage`, 사전 예약액 0으로 기록하며 완료 후 사용량을 저장한다.
- 기존 요청 한도 저장값·과거 예약 행은 호환 목적으로 유지하되, 신규 실행 판단에 추정 예약액을 사용하지 않는다.
- 월 예산·최근 계정 잔액 확인·모델/인증·API 및 검색 동의·동일 요청 중복 차단은 유지한다. 결과 불명·누락 사용량·취소·시간 초과는 새 실행을 차단한다.
- 보고된 출력 토큰이 요청한 기술적 출력 한도보다 크다는 사유만으로 결과 불명으로 분류하지 않는다. 검색 도구 최대 1회 검사는 유지한다.
- 최초 검색의 기술적 출력 한도는 승인된 9,000토큰이다. 일반 제작의 저장된 출력 설정은 변경하지 않았다.
- 설정/제작 동의 화면에서 요청별 USD 입력 및 추정 사전 예약을 제거했다. 기존 URL·CSRF·Origin·필수 동의를 유지한다.

## 검증

- 변경 영역 Fake 테스트 200개 PASS, 변경 Python 파일 Ruff PASS, diff 검사 PASS.
- 첫 Fake 실행에서 공통 Options의 3,000토큰 제한을 발견해 9,000으로 일치시킨 뒤 실패 항목만 재검증했다. 오래된 GUI 문구 기대값도 현재 검색·분석·대본 요청 안내에 맞췄다.
- 샌드박스의 TestClient 첫 요청이 멈춰 해당 실행을 중단했다. 일반 사용자 권한에서 별도 테스트 데이터와 외부 I/O 금지 fixture로 GUI 검증을 완료했다.
- 전체 회귀·CI·CLI 인증 검증은 실행하지 않았다.

## 승인된 운영 조치 및 실호출

- SQLite Backup API로 일관된 백업을 보존한 뒤, 사용자가 삭제를 승인한 기존 $3.055 결과 불명 예약 한 행만 삭제했다. 연결된 과거 실패 작업·분석 실행·보고 사용량은 보존했다. 로컬 원장 삭제는 공급사 사용량/청구 취소가 아니다.
- 기존 인증과 계정 잔액 확인을 재사용했다. 월 예산 $100과 기타 저장 설정은 변경하지 않았다.
- 기존 IntelligenceService와 Claude 어댑터로 검색 1회만 실행했다. 모델 `claude-sonnet-4-6`, IT/최근 24시간/후보 1건, 출력 9,000토큰, 검색 도구 최대 1회, 제한시간 60초.
- 실제 결과: HTTP 2xx, 종료 `end_turn`, 실행 ID 10, 검색 도구 1회, 출처 후보 1건 저장. 원문 본문·사실 검증은 NOT VERIFIED.
- 응답 사용량: 입력 11,932 / 출력 1,323 / 검색 1회. 저장 단가 기반 사후 추정 $0.065641, 실제 공급사 청구액 NOT VERIFIED.
- 인증 조회·분석·대본·음성·영상·재시도·다른 Provider 전환 0회.
- 삭제 승인된 행을 제외한 기존 DB 행·설정 보존, DB 무결성 ok/revision 0013. 기존 MP4 3개 및 DPAPI/세션 파일의 해시 동일.
- 운영 프로세스 재시작/데이터 경로 변경 없음. 실호출은 최신 코드의 별도 단발 프로세스로 실행했다. 운영 앱의 Python 프로세스에는 이번 변경이 아직 재시작 적용되지 않았다.

실행 백업·상세 증거는 Git 제외 `validation-output/api-usage-accounting-20261017/`에 보존한다. PR #33·main은 변경하지 않는다. 추가 실호출은 수행하지 않는다.

# 샘플 MP4 보존 상태

신규 샘플 MP43개는 실제 제작·전체 디코딩/길이/규격 검증을 완료했다.
이 개발 PC의 후보 폴더와 별도 작업 증거 폴더에 보존한다.
파일별 SHA256/크기는 상위 MEDIA_UPLOAD_STATUS.json과 manifest.json에 기록했다.

자동 승인 심사는 이3개를 Git stage하는 동작을 바이너리 업로드 제한으로
두 번 거절했다. 파일이 신규 합성 무음 H.264 MP4이며 EXE/DLL/Setup/키/DB/
운영 미디어가 아님을 입증한 뒤 재검토했으나 같은 거절이 유지됐다.
다른 API·파일명 변경·압축/인코딩·간접 실행으로 우회하지 않았다.

따라서 GitHub에는 이미지9개·원본·poster·생성/가공/권리/해시 기록만 있고,
MP43개는 원격 등록되지 않았다. 로컬 Samples.catalog의12개 로딩PASS는
로컬 파일이 존재하는 환경의 결과이며, GitHub checkout만으로12개 미디어가
모두 제공된다고 주장하지 않는다. 이 폴더는 제품에 적용되지 않은 후보 자료다.

추가로 필요한 것은 위3개 샘플 영상만의 GitHub 등록을 명시적으로 허용하는
승인 또는 승인된 미디어 artifact 저장소다. 제품 실행 바이너리 공개 배포는
그 승인에 포함하지 않는다.

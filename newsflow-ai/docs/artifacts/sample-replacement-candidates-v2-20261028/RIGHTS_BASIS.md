# 신규 샘플 후보의 권리 근거와 미확인 범위

## 기존12개

이전 `sample-rights-evidence.json`의 생성 대화 없음/원본 콜라주 없음/
파일별 상용 재배포 허락 없음 판정을 재사용한다. 새 증빙은 제공되지 않았다.
PNG9개/MP4 3개를 재해시·재감사하지 않았고 기존 SHA와 위험 관찰을
FILE_RIGHTS_MATRIX.md에 연결했다. 전부 rightsVerified:false를 유지한다.
기존 파일·매니페스트·사용자 복사본·프로젝트 참조는 수정하지 않았다.

## 신규 이미지9개와 영상3개

- 이 작업의 승인 범위에서 내장 `image_gen`으로 독립적인 새 이미지9개를
  생성했다. 운영 API 키/외부 유료 REST·SDK 호출0이다. 생성 도구 호출은
  실제10회이며1개는 거절 후보,9개가 최종 후보다. 이를 Fake 생성이나
  제품 OpenAI Adapter의 실계정 성공으로 표시하지 않는다.
- 기존 이미지/사진/콜라주를 참조 입력으로 보내지 않았다. 입력은 이 작업에서
  작성한 텍스트 prompt뿐이며 원본 PNG bytes와 exact prompt를 보존했다.
  도구가 모델 ID를 제공하지 않아 특정 이미지 모델명은 추측하지 않는다.
- 로봇/고양이/드래곤·가상 도시·고양이·환경 개념·AI/전기 이동/경제 개념이다.
  명백한 실제 인물/공급사 로고/기성 캐릭터 식별은 최종 후보에서 확인하지 못했다.
  최초 전기차 그림의 작은 표식/제품 외관 모호성은 제외 사유로 기록하고,
  최종 후보는 차량 없는 추상 배터리/충전 형태로 다시 생성했다.
- MP4 3개는 이 새 이미지에서만 파생한 3×4초 무음 정지영상 미리보기다.
  외부 음원·ChatGPT 음성·유료 TTS/영상 공급사는 사용하지 않았다.
  실제 AI 캐릭터 움직임/음성/완성 쇼츠/편집 원본 프로젝트로 표시하지 않는다.
- 규격화는 FFmpeg scale/crop/PNG export뿐이고 raw 원본은 유지한다.
  영상의 글꼴은 기존 확인된 Noto Sans KR 및 SIL OFL 고지를 함께 보존한다.
  새 글꼴·개인 사진·상표·음원·실제 뉴스 데이터는 추가하지 않는다.

## 확인한 공식 약관

[OpenAI Terms of Use](https://openai.com/policies/terms-of-use/)의 Content 절과
[Services Agreement](https://openai.com/policies/services-agreement/) §4.1은
각각 적용되는 사용자/고객과 OpenAI 사이에서 Output 소유권을 규정한다.
동시에 입력 권리·출력 사용 책임과 출력 비유일성을 규정하므로, 이 근거는
배타적 저작권 또는 모든 제3자 권리에 대한 보증이 아니다.
[Service Terms](https://openai.com/policies/service-terms/)도 함께 확인했다.
ChatGPT Voice의 별도 상용 제한을 피하기 위해 음성 출력은 사용하지 않았다.

이번에 직접 확인한 것은 **이 세션의 생성·입력·가공·파일 동일성 및 일반 약관
근거**다. 배포 주체에 실제 적용되는 계정/계약과 그 주체의 재배포 권한 확인
기록은 제공되지 않았다. 시각 검사만으로 상표·캐릭터/사진의 법적 clearance를
완료했다고 표시하지 않는다. 따라서 후보도 rightsVerified:false,
commercialRedistribution:CONDITIONAL, activeInProduct:false를 유지한다.

필요한 추가 입력은 새 그림 자체가 아니라, 이 생성 Output을 사용하려는
배포 주체의 적용 계약/사용 권한 확인 기록이다. API 키나 결제 비밀값을
제출할 필요는 없다. 원래 샘플을 계속 배포하려면 별도로 원래 파일의
생성·입력·가공·상용 재배포 증빙이 있어야 한다.

## 교체 준비 범위

새 자산은 별도 ID(`*-v2`)·immutable hash·version2로 관리한다.
후속 패키징에서 권리 확인된 파일만 선택하고 원래 v1 catalog와 기존 사용자
복사본/숨김 상태는 보존한다. 기존 참조를 임의로 새 파일에 재연결하거나
업데이트 시 사용자가 숨긴 샘플을 다시 켜지 않는다.
이번 단계는 교체 후보 제작·증거 등록이며 제품 manifest/소비자 설치본을
교체하지 않는다. gallery.html과 manifest.json에서 실제 산출물을 확인할 수 있다.

## 최종 상태

**CONDITIONAL** — 승인된 수정의 운영 반영, Chrome 인증, 한도 복원, 공식 견적 확인과 데이터 보존 확인을 완료했다. 실제 유료 영상 생성은 수행하지 않았으므로, 생성·재생·최종 합성의 성공 여부는 이번 결과에 포함하지 않는다.

Chrome에는 **Kling O3 Standard, 30초(5장면 × 6초), 9:16, 음성 포함** 설정과 **공식 견적 US$3.360**이 표시된다. 장면별 견적은 US$0.672이며, 실행 1회 한도는 원래 값인 **US$5.00**으로 복원했다. 견적은 실제 청구액이 아니며, 사용자가 생성 여부를 결정하기 전에 유효기간을 다시 확인해야 한다.

## 확인한 문제와 수정

- 생성 버튼이 작동하지 않았던 원인은 기존 운영 연결이 견적 조회까지만 허용하고 영상 제출·상태 조회·다운로드를 연결하지 않았기 때문이다. 이 문제로 원격 영상 생성 요청이 발생하지는 않았다.
- 기존 작업의 한도를 사용자가 수정하지 않았는데 UI 기본값 10으로 덮어쓸 수 있었다. 이제 기존 작업은 저장된 한도를 기본으로 사용하고, 사용자가 직접 편집한 값만 작업별로 적용한다. 기본값 10은 신규 작업에만 사용한다.
- 유효한 미전송 견적에서 한도만 변경하면 장면·견적 금액·원 견적 시각·기존 견적 이력을 보존한다. 새 한도에 계획과 승인 해시를 다시 연결하며, 이전 승인 해시는 거절한다. 15분 유효기간을 연장하지 않는다. 만료되거나 영상 설정이 바뀌면 새 견적을 받아야 한다.
- 설정 저장 API는 안전한 상태 값과 견적 보존 여부를 반환한다. 화면은 견적이 유지됐을 때 중복 견적 요청을 열지 않는다.
- 수동 캐릭터 영상 연결은 기본적으로 비활성이다. 이번 승인에 따라 해당 운영 연결을 활성화했으며, 기존 견적·동의·1회 한도·결과 불명 보호를 거쳐 제출·상태 조회·다운로드가 가능하도록 연결했다. 스토리 자동 실행, SNS 게시, 자동화 예약 또는 전역 외부 실행 권한을 함께 열지 않았다.
- 영상 길이·화질·출력 크기·음성에 붙어 있던 반복 설명 네 항목을 제거했다. 설정 이름과 선택값, 실제 오류, 비용 및 승인 정보는 유지했다.

# 저장 스토리 재사용 · 음성 포함 15초 영상 견적 준비

2026-10-29. 개발·집중 검증 완료, 운영 반영 및 실제 견적 조회 전이다. 실제 영상 생성 성공으로 표시하지 않는다.

## 사용자 요청과 범위

현재 사용자가 보고 있는 Chrome의 NewsFlow AI에서 기존 캐릭터·스토리를 재사용해 Kling 3.0 Standard, 15초, 9:16, 모델 자체 소리 ON으로 제작한다. 한국어 대사는 저장된 대사를 우선 사용하고 없으면 한글 장면 요약을 사용한다. 실제 발음·화질·내용은 결과 재생 후 검토한다. ElevenLabs·Claude의 추가 유료 호출은 하지 않는다.

## 최소 연결 수정

- 캐릭터 제작실의 명시적인 `이 스토리로 새 영상` 버튼으로 기존 스토리·참조 PNG를 새 로컬 프로젝트에 복사한다. 원본 결과 불명 작업과 과거 전송 자료는 수정하지 않는다.
- 기존 인증·Origin·CSRF를 통과하는 정확한 재사용 API를 추가했다. 로컬 복사 멱등성과 복사 결과 불명 상태를 보존하고 자동 재요청하지 않는다.
- 새 작업은 스토리 검토 상태에서 시작하고, 별도의 버튼으로 참조 전송과 공식 견적을 1회 조회한다. 5개 이야기 계획은 15초 단일 영상 요청 하나에 통합한다.
- 첫 실행 권한은 **견적 전용**, `allow_submit=false`, 총 US$3 그대로다. 아직 새로운 공급사 생성 요청을 허용하지 않는다.
- 이전 두 시험의 보수적 노출 US$1.760을 포함해 한도를 계산한다. 기존 사용 기록·결과 불명·원본 대본·기존 승인 횟수를 초기화하지 않는다.
- 후속 생성은 같은 작업의 명시 승인에 한해 허용한다. 소액 견적은 총 US$3 그대로 처리할 수 있으며, 초과 시 사용자 추가 승인 없이는 한도를 올리지 않는다. US$4.50 확대는 가능한 승인 경계일 뿐 현재 승인되거나 운영 적용된 값이 아니다.
- 기존 일일 한도와 이전 불명 영상 비용이 충돌하는 실제 값도 확인했다. 추가 승인 기록이 있는 새 요청에서만 별도 일일 누적 한도 근거를 사용하고, 원래 작업 한도·대본 및 견적 지문은 유지한다.
- 공급사 제출 오류에는 HTTP 상태·고정 분류만 안전하게 보존한다. 응답 본문·헤더·URL·키를 기록하지 않는다. 실패·결과 불명 요청은 재전송하지 않는다.

## 집중 검증

- 재사용·API·원본 보존·실행 범위: 69 PASS / 0 FAIL / 0 ERROR.
- 이후 일일 누적 승인 및 소액 승인 영향 검사: 6 PASS / 0 FAIL / 0 ERROR. 앞선 검사와 겹치는 항목이 있어 합산하지 않는다.
- 기존 안전 진단 70 PASS는 재실행하지 않고 재사용했다.
- TypeScript·Vite 빌드 PASS. 기존 폰트/청크 경고만 있으며 전체 회귀·Guard 감사·디자인 재검토·패키징은 반복하지 않았다.
- 재사용 서비스 6개와 연계 2개는 JUnit을 보존했다. 실행 정책 61개는 하위 에이전트의 pytest 출력 근거이며 JUnit은 생성하지 않았다. 검증 형식을 구분해 기록한다.

## 준비된 운영 반영

현재 실행 중인 Python에 새 API·연결을 적용하려면 정상 Stop·Start 1회가 필요하다. 기존 Chrome 자동 열기·인증 연결은 보존하고 실행기의 정확한 callback 연결 부분만 수정한다. 준비된 반영 파일은 Python/실행기 7개와 React 정적 자산 2개다.

사용자 승인 전에는 운영 파일·승인 파일·프로세스를 바꾸지 않는다. 승인 뒤 새 Chrome 인증에서 스토리 복사와 소리 ON·15초를 함께 확인하고 공식 견적까지만 진행한다. 견적 금액과 기존 미확정 노출을 사용자가 확인하기 전 새 유료 생성은 진행하지 않는다.

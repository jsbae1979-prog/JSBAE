# Windows 11 운영 점검 (Phase 5F)

기본 실행은 기존 `setup.bat` / `run.bat`입니다. Python 3.12, 영상 도구, 글꼴, 데이터 이전 절차는 [README](../README.md)를 따릅니다. 데이터는 `%LOCALAPPDATA%\NewsFlowAI`에 유지됩니다. 이 단계에서는 유료 AI, OAuth 로그인, SNS 업로드·게시를 시험하지 않습니다.

## 로그인 시 자동 시작 — 선택 사항

1. `run.bat`를 한 번 실행해 설치를 완료합니다. 프로그램을 이동·업데이트했다면 다시 실행합니다.
2. 설정 → **내 PC 운영 점검**에서 현재 상태와 안내를 읽습니다.
3. 다음 Windows 로그인부터 앱을 시작하는 데 동의할 때만 체크하고 **동의하고 자동 시작 등록**을 누릅니다.
4. 작업 스케줄러에 현재 사용자 전용 `NewsFlowAI-…` 작업이 생성됩니다. 관리자 권한, 비밀번호, SYSTEM 계정, 최고 권한은 사용하지 않습니다. 이미 관리자 권한으로 실행 중이면 등록을 거부하므로 일반 권한으로 다시 실행하세요. 최소 권한 설정이 무시될 수 있는 기본 제공 Administrator 계정(RID 500)도 차단합니다. 권한 오류 시 앱을 관리자 권한으로 재실행해 우회하지 말고 수동 실행을 유지하세요.
5. 등록은 지금 앱을 다시 실행하지 않습니다. 재부팅 후 해당 사용자가 **로그인해야** 실행합니다. 로그인하지 않은 PC나 꺼진 PC에서는 제작하지 않습니다. 절전 해제도 요청하지 않습니다.
6. 해제할 때 같은 화면의 별도 동의 후 **자동 시작 해제**를 누릅니다. 실행 중인 앱·예약·데이터는 삭제하거나 종료하지 않습니다.

자동 시작은 설치가 끝난 프로젝트 전용 Python을 사용하고 기존 `newsflow.main.run` 실행·소켓·파일 잠금을 재사용합니다. 패키지를 자동 설치하지 않습니다. 자동 시작 주소는 `127.0.0.1:8765`로 고정되며 환경변수로 LAN 주소나 다른 포트를 지정해도 적용하지 않습니다. 이미 앱이 켜져 있거나 포트가 점유되면 두 번째 프로세스는 실패 종료합니다. 자동 재시작 루프를 만들지 않습니다.

작업 이름은 Windows 사용자 SID에서 만들고 설치·데이터 경로를 소유 표시와 실제 실행 정의로 대조합니다. 다른 설치의 작업이나 수정된 작업은 덮어쓰거나 지우지 않습니다. 원래 설치에서 해제하거나 사용자가 작업 스케줄러에서 해당 작업의 실행 경로를 확인해야 합니다. 등록·해제 결과가 불명확하면 자동 재전송하지 않습니다. 화면을 새로고침하고 실제 작업 상태를 확인하세요.

자동 시작 경로는 로컬 상태만 복구하며 기존 유료 AI 영상 작업의 백그라운드 제출·조회 스레드를 재개하지 않습니다. 기존 예약은 Phase 5E의 Offline 제작·검토 정책을 유지합니다. 앱 안에서 사용자 명시적 실행에 적용되던 승인·비용·결과 불명 보호는 유지됩니다. 자동 시작 동의는 유료 AI나 게시 승인이 아닙니다.

## 종료·재시작·절전

- 정상 종료: 실행 창에서 **Ctrl+C**. 브라우저 탭 닫기는 앱 종료가 아닙니다.
- 종료 기록: 운영 점검의 최근 자동 시작 기록과 `logs/execution.log`를 확인합니다. `starting/running`은 마지막 기록일 뿐입니다. 강제 종료 후 남은 기록을 현재 실행 성공으로 표시하지 않습니다. 작업 스케줄러의 마지막 실행 결과도 확인하세요.
- 오류: `run.bat`로 설치와 오류 안내를 확인합니다. 포트 점유 시 기존 프로그램을 확인하며 다른 포트를 자동 선택하거나 프로세스를 임의로 종료하지 않습니다.
- 예약: 앱이 실행 중일 때만 동작합니다. 시작·절전 복귀 시 90초 이내의 예약 1건만 기존 규칙대로 실행하고 그보다 지난 예약은 건너뜁니다. 여러 날의 누락분을 몰아서 제작하지 않습니다.
- 제작 중 종료: 기존 Autopilot의 중단/확인 대기 상태와 산출물 보존을 재사용합니다. 결과 불명 요청을 자동 성공 또는 재제출하지 않습니다. 작업 화면에서 확인 후 안전한 재시도를 선택하세요.
- Windows 업데이트·로그아웃·강제 종료는 작업을 중단할 수 있습니다. 복구 정책의 자동 테스트와 실제 PC 재부팅·절전 검증은 별개입니다.

## 한국어 음성

운영 점검 → **음성 확인·샘플 듣기·청취 기록**을 엽니다. 기존 SAPI 목록·OneCore 읽기 전용 탐지와 고정 샘플을 사용합니다. 샘플에는 `2026-10-15 14:30`, `KOSPI`, `3.5%`, `AI`, `$1,250,000`이 포함됩니다.

Windows 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션에서 음성 설치 상태를 확인하세요. OneCore에만 있는 음성은 이 앱의 SAPI에 보이지 않을 수 있습니다. 앱은 음성을 설치하거나 레지스트리를 수정하지 않습니다. 비공식 레지스트리 복사 대신 무음 검토영상 또는 Windows 지원 경로를 이용하세요.

[한국어 청취 확인표](korean_tts_listening_checklist.md)에 따라 직접 듣고 기록합니다. 발음·속도·금액·날짜와 영상 자막 동기를 사람이 평가하기 전에는 **NOT VERIFIED**입니다. CI에서 WAV/MP4가 생성된 사실만으로 청취 품질을 PASS로 바꾸지 않습니다.

## 사용자 PC 증거 수집

운영 점검 화면의 모든 항목은 **NOT VERIFIED**로 시작합니다. 직접 확인한 항목만 PASS/FAIL로 바꾸고 동의 후 저장합니다. 자동 테스트로 이 기록을 채우지 않습니다.

| 순서 | 직접 확인할 내용 | 보존할 증거 |
|---|---|---|
| 1 | `run.bat` 실행·종료·중복 실행·포트 점유 안내 | 오류 안내 화면, 비밀값 없는 실행 상태 |
| 2 | 예약 활성화·KST 다음 실행 시각 | 예약 화면 |
| 3 | 승인된 공개 RSS 수집·원문 검토 | 출처·기사 화면 (개인정보 제외) |
| 4 | 30·45·60초 각각 제작·브라우저 재생 | MP4, 해시, 재생 화면 |
| 5 | 한국어 발음·금액·날짜·자막 동기 | 기존 청취 기록, 사람이 본 결과 |
| 6 | 앱 재시작 후 기사·설정·완료 영상 보존 | 전후 영상 SHA256 비교 |
| 7 | 동의한 자동 시작 등록 후 재부팅·로그인 | 작업 설정, 상태 화면 |
| 8 | 절전 중 지난 예약·복귀 후 다음 예약 확인 | 누락 건너뛰기 이력과 다음 KST 시간 |
| 9 | 자동 시작 해제·다시 로그인 | 작업 없음, 수동 실행·데이터 유지 |

**내 점검 결과 내려받기**는 고정 항목·자가 보고 출처·시각·판정만 JSON으로 내보냅니다. 키·토큰·전체 경로·이름·DB를 포함하지 않습니다. 음성 청취 JSON과 MP4는 별도 자료입니다. 스크린샷·영상에 개인정보가 있다면 공개 저장소에 올리지 마세요. 이 JSON은 사람이 작성한 자기 보고이며 암호학적 검증이나 CI 판정이 아닙니다.

## 확인한 공식 자료

2026-10-16 KST에 Microsoft 문서 HTTP 200 및 본문을 확인했습니다. 이는 사용자 PC의 실제 동작 검증을 대신하지 않습니다.

- [Task security contexts](https://learn.microsoft.com/en-us/windows/win32/taskschd/security-contexts-for-running-tasks): interactive token과 최소 권한.
- [TaskFolder.RegisterTask](https://learn.microsoft.com/en-us/windows/win32/taskschd/taskfolder-registertask): TASK_CREATE와 로그인 유형, 기존 작업을 강제 갱신하지 않음.
- [Logon trigger example](https://learn.microsoft.com/en-us/windows/win32/taskschd/logon-trigger-example--scripting-): 사용자 로그인 트리거.
- [WakeToRun](https://learn.microsoft.com/en-us/windows/win32/taskschd/taskschedulerschema-waketorun-settingstype-element): 절전 해제 설정.
- [GetInstalledVoices](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer.getinstalledvoices): 설치된 SAPI 음성 조회. Windows 설정의 OneCore 표시와 이 API의 노출이 항상 같다고 가정하지 않음.

제약: 자동 시작은 프로젝트 폴더와 해당 `.venv`가 유지되어야 합니다. 같은 Windows 사용자 권한으로 설치 파일을 악의적으로 변경하는 공격을 격리하는 설치 프로그램/서명 시스템은 이번 범위가 아닙니다. 현재 SID 형식이 지원되지 않거나 기업 정책이 막으면 등록하지 않고 수동 실행을 사용합니다. EXE 설치 프로그램은 제공하지 않습니다.

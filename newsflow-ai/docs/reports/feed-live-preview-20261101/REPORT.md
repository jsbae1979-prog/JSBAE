# 피드 편집 간소화 및 자동 미리보기

## 변경 결과
- 기본 화면: 피드 제목, 핵심 설명, 접을 수 있는 배치·색상·자르기, 새 버전으로 저장.
- 제목 후보·캡션 구성, 이미지 선택·업로드, 출처·크레딧, 원문 참고, 초안 저장, 성과 입력은 고급 편집 안에 보존.
- 별도 미리보기 적용 버튼 제거. 제목·설명·배치·색상·자르기·이미지 변경 시 250ms 동안 입력을 모아 기존 로컬 합성기로 자동 미리보기를 요청한다. 원격 이미지 생성 API는 사용하지 않는다.
- 연속 편집은 이전 요청을 취소하고 늦은 응답을 버린다. 프레임 단위 실시간 렌더링은 아니며 로컬 합성 시간이 필요하다. 입력 중 조작을 막지 않는다.
- 미리보기는 작업 DB나 저장 버전을 갱신하지 않는다. 임시 합성 미리보기 파일만 생성한다. 저장은 명시적인 버튼 조작으로만 수행한다.
- 실패 시 마지막 정상 이미지를 유지하고 입력 수정 안내를 표시한다. 긴 글을 자동으로 줄이거나 자르지 않는다.
- 이미지 교체 후에도 저장하지 않은 제목·배치·자르기 변경을 유지하고 새 크레딧을 적용한다.
- 큰 미리보기와 확대 팝업, 개별 TOP 편집, 이전 버전은 유지한다.

## 발견한 추가 연결 누락
기존 /api/feed-batches/{id}/items/{1..3}/design-upload POST는 등록돼 있었지만, HTTP 미들웨어의 multipart 경로 목록에서 빠져 있어 415를 반환했다. 정확한 경로 하나만 기존 로컬 업로드 검사에 연결했다. 20MB 이미지·1개 파일·10개 필드·Origin·서명 CSRF 및 raster 검증을 유지한다. 임의 경로의 multipart는 여전히 거부한다. 기존 캐릭터 업로드 제한 10MB는 변경하지 않았다.
새 POST 경로는 추가하지 않았으며 두 actions 레지스트리의 기존 등록을 재사용한다.

# 캐릭터 쇼츠: 한 주제 제작 흐름 및 등록 정보 수정 연결

사용자의 최신 지시에 따라 고급 일괄 제작·기록 관리, 선택 주제 일괄 제작, 제작 대기열(삭제 버튼 포함), CSV 주제 가져오기를 React 화면에서 제거했다. 오른쪽 수동 상태 변경 선택상자도 제거했다. 주제 후보를 생성하거나 직접 저장하고, 목록에서 하나를 선택하여 위의 스토리 자동 생성 버튼으로 이어지는 흐름만 제공한다. 후보 개수 설정은 주제 후보 수이며, 여러 영상을 일괄 제작하는 설정이 아니다. 선택은 하나이고 주제를 바꾸면 이전 선택이 해제된다.

CharacterTopics의 대기열 조회·생성·실행·승인·삭제 및 CSV·상태 변경 요청 코드를 제거했다. 기존 대기열·주제·작업·영상과 비용 기록은 삭제하거나 변경하지 않았다. 과거 기록 호환성을 위한 서버 코드는 유지하며 이 화면에서는 호출하지 않는다. 이전 대기열 삭제 보고서의 UI는 이번 사용자 방향 변경으로 대체된다.

‘캐릭터 특징 수정’ 저장 오류는 과거 제작 작업의 등록 버전 1과 현재 등록 정보 버전 2의 충돌로 재현했다. 수정창은 동일 ID의 최신 카탈로그 등록 정보·이미지·버전을 사용하도록 변경했다. 기존 작업 스냅샷은 그대로 남는다. 수정창을 연 뒤 다른 곳에서 갱신한 경우에는 저장을 강제하지 않는다. 실패 후 기존 인증 경로로 등록 목록을 한 번만 조회해 버전 충돌을 구분하고, 입력한 내용을 그대로 유지한다. 조회 실패나 원인이 확인되지 않은 오류를 ‘필수 항목 누락’으로 단정하지 않는다. 자동 재저장·재전송은 없다.

작업 이력의 ‘새 작업’과 ‘새 스토리 입력’은 동일 캐릭터가 현재 등록돼 있으면 최신 등록 특징을 새 초안에 연결한다. 저장 작업의 참조 이미지와 캐릭터 스냅샷은 변경하지 않는다. 앞서 수정한 새 초안의 이미지 미리보기도 유지한다.

이번 변경은 React 컴포넌트와 해당 화면 전용 CSS뿐이다. Python·DB schema·실제 API 실행 조건·승인 및 결과 불명 보호는 변경하지 않는다. 추가 운영 재시작 없이 기존 정적 파일 반영 절차를 사용한다. API 연결 확인이나 유료 생성은 실행하지 않는다. Claude 연결 확인의 기존 유효기간 만료는 별도 사용자 연결 확인이 필요한 상태로 유지한다.

검증은 합성 프로필과 Fake를 사용한다. 단일 주제 선택 및 메인 스토리 연결, 과거 대기열 무변경, 수정 전후 이미지·프로필 분리, 동시 수정 입력 보존, 일반 오류 안내, TypeScript·React 빌드를 검사한다. 전체 회귀·Guard 감사·패키징·실제 유료 요청은 반복하지 않는다. 정확한 결과와 반영 SHA는 SAFE_EVIDENCE.json에 기록한다.

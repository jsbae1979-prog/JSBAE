NewsFlow AI를 시작해 볼까요?

Windows 11용 안내입니다. 처음 한 번만 준비하면 다음부터는 run.bat를 더블클릭하면 됩니다. 설치에는 인터넷 연결이 필요합니다.

1. Python 준비

Python 공식 Windows 다운로드에서 Python 3.12의 Windows installer (64-bit)를 설치하세요. 설치 화면의 Add python.exe to PATH를 선택하세요. 다른 버전만 설치되어 있으면 실행할 수 없습니다.

프로젝트 ZIP을 먼저 압축 해제하세요. ZIP 안에서 run.bat를 직접 실행하지 마세요.

2. 영상 도구 준비

FFmpeg 공식 다운로드 안내에서 연결된 Windows 빌드를 선택해 압축 해제하세요. bin 폴더 안에 ffmpeg.exe와 ffprobe.exe가 모두 있어야 합니다.

  1. 시작 메뉴에서 “환경 변수”를 검색해 사용자 계정의 환경 변수 편집을 엽니다.
  2. 사용자 변수의 Path → 편집 → 새로 만들기에 압축 해제한 bin 폴더의 전체 경로를 넣습니다.
  3. 실행 중인 NewsFlow 창을 종료한 뒤 다시 실행합니다. 기존 Path 항목은 지우지 마세요.

앱은 도구를 임의 다운로드하거나 보안 검사를 끄지 않습니다. 배포자의 서명·체크섬 안내를 확인하세요.

3. 준비 상태 확인

setup.bat를 더블클릭합니다. 앱 전용 Python 환경과 필요한 패키지를 설치하고, 영상 도구·한국어 글꼴·저장 공간·DB를 확인합니다. 오류가 있으면 해당 안내를 해결하고 다시 실행하세요. 실패를 성공으로 표시하지 않습니다.

한국어 글꼴은 Windows의 맑은 고딕을 사용합니다. 한국어 음성(선택): Windows 설정 → 시간 및 언어 → 언어 및 지역 → 한국어 → 언어 옵션에서 음성(텍스트 음성 변환)을 설치한 뒤 NewsFlow를 종료하고 run.bat를 다시 실행하세요. 앱은 SAPI에 보이는 한국어 음성만 사용하며, 없어도 무음 영상으로 시작할 수 있습니다. 설치한 음성이 앱에 보이지 않으면 설정 → 음성 화면의 안내(SAPI 미노출)를 확인하세요.

4. 실행하고 첫 영상 만들기

  1. run.bat를 더블클릭하고 실행 창을 유지합니다.
  2. 브라우저 주소창에 http://127.0.0.1:8765를 입력합니다.
  3. 홈의 처음 설정하기를 따라 진행한 뒤 체험 영상 만들기를 누릅니다.
  4. 완료된 영상을 재생하고 대본과 출처를 확인합니다. 체험 뉴스는 실제 보도가 아닙니다.

실제 계정 연결과 SNS 게시 기능은 차단되어 있습니다.

5. 실제 뉴스로 만들기 (선택)

체험이 끝나면 사이드바 뉴스에서 공개 RSS를 등록하고 연결 테스트 → 사용하기 → 지금 뉴스 모으기를 누른 뒤, 자동 제작에서 실제 콘텐츠 제작을 고르세요. 외부 AI 대본과 한국어 음성은 사이드바 설정의 AI 연결·API 키·사용량, 한국어 음성·속도·미리 듣기에서 따로 켭니다(선택 사항). 실제 콘텐츠는 대본과 완성 영상에서 반드시 멈추고 여러분의 확인을 기다립니다.

자세한 순서와 화면 문구는 프로젝트 폴더의 안내서 docs\user_guide_realcontent.md를 메모장이나 브라우저로 열어 읽으세요. 확인 결과는 docs\windows_user_verification_checklist.md에 기록합니다.

6. 영상 제작 모드: 기본 모드와 AI 고품질 모드 (선택)

기본 모드는 이 PC의 FFmpeg로 장면마다 카드나 내 이미지로 영상을 만듭니다. 외부 영상 API를 쓰지 않고 비용이 없으며 언제나 사용할 수 있습니다. 자동 제작도 기본 모드로 만듭니다.

AI 고품질 모드는 고른 장면만 외부 AI 영상 공급사(Higgsfield, 유료)로 만들고 같은 FFmpeg로 자막·음성·출처를 얹습니다. 처음에는 꺼져 있습니다. 사이드바 설정의 AI 영상(선택)·모델·비용 한도에서 승인·작업별/월 한도·공식 문서로 확인한 모델·API 키를 저장한 뒤, 고급 모드 Video Studio의 AI 고품질 제작 (선택)에서 장면을 고르고 예상 비용을 확인해야 요청합니다. AI 장면에는 “AI 생성 장면 · 실제 현장 영상 아님” 표시가 들어갑니다.

자세한 순서는 안내서 docs\user_guide_ai_video.md를 읽으세요.

7. 종료·데이터·오류 해결

종료하려면 실행 창에서 Ctrl+C를 누릅니다. 브라우저 탭만 닫으면 프로그램은 계속 실행됩니다. “이미 실행 중”이면 기존 창과 주소를 확인하세요. 프로그램은 다른 포트를 자동 선택하지 않습니다.

데이터: %LOCALAPPDATA%\NewsFlowAI
영상: %LOCALAPPDATA%\NewsFlowAI\outputs\videos
로그: %LOCALAPPDATA%\NewsFlowAI\logs
음성 미리 듣기: %LOCALAPPDATA%\NewsFlowAI\voice-preview
청취 결과 기록: %LOCALAPPDATA%\NewsFlowAI\voice-listening
외부 AI 키(암호화, 공유 금지): %LOCALAPPDATA%\NewsFlowAI\ai-key.dpapi
AI 영상 키(암호화, 공유 금지): %LOCALAPPDATA%\NewsFlowAI\video-ai-key.dpapi
AI 생성 장면 영상: %LOCALAPPDATA%\NewsFlowAI\ai-clips

업데이트 전 프로그램을 종료하고 데이터 폴더를 백업하세요. 기존 data/newsflow.db가 발견되면 README의 안전한 이전 절차를 따르세요. 기존 DB나 session.key를 지우는 방식으로 오류를 해결하지 마세요.

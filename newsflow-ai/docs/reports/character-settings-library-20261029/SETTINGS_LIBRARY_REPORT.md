# 캐릭터 영상 길이·화질·내 캐릭터 저장 수정

2026-10-29. 개발·집중 검증 후 사용자의 명시적 승인을 받아 운영 반영과 정상 Stop·Start 1회를 완료했다. 개발 검사와 실제 운영 확인은 아래에서 구분한다.

## 수정 내용

- 저장 스토리라는 이유로 총길이를 잠그던 UI와 서비스 조건을 수정했다. 새 복사본과 안전한 미제출 작업은 15~60초를 5초 단위로 선택하고 5개 장면을 균등 배분한다(30초=6초×5). 장면당 길이는 선택 모델의 지원 범위여야 하며, 기존 3~4장면 스토리는 이 방식으로 길이를 바꾸지 않는다. 스토리 내용과 원본·이미 제출·결과 불명·청구·승인 자료는 바꾸지 않는다. 기존 견적의 원래 스토리·길이·payload는 이력으로 보존하고 다시 견적한다.
- Kling 3.0 Standard는 공식 API에 화질 파라미터가 없으므로 고정 Standard로 표시한다. Kling O3는 공식 `mode` 값 std/pro/4k를 수동 선택하고 요청에 그대로 연결한다. 자동 Pro/4K 상향은 없다. 과거 O3 model_default 저장 자료는 변경하지 않고 실행 시 Standard로 해석한다.
- AI 생성 모드와 최종 로컬 출력 크기를 구분해 표시한다. 최종 출력은 720p·1080p·4K이며, 로컬 확대가 원래 영상의 세부 품질을 늘린다고 주장하지 않는다. Pro/4K 비용과 계정 권한은 실제 공식 견적·생성 전 미확정이다.
- 기본 해제된 ‘내 캐릭터에 저장’ 체크박스를 추가했다. 사용자가 체크할 때만 사용자 프로필의 콘텐츠 주소형 PNG와 캐릭터 목록 정보를 저장한다. 동일 이미지 재등록은 중복 생성·기존 이름 덮어쓰기 없이 처리한다. 미체크는 내 캐릭터 목록에 등록하지 않는다. 제작에 필요한 작업용 참조 PNG 보존과는 별개다. 내 캐릭터 선택은 검증된 자산 ID를 통해 새 참조로 실제 연결하며, 별도 제작 이력이나 AI 성공 기록을 만들지 않는다.

## 정상 로컬 합성의 이전 시험 제한 분리

운영 프로필에서는 무결성 검증을 거친 과거 스토리 재사용 승인이 이미 `allow_submit=false`로 닫힌 경우, 해당 시험 wrapper를 새 실행에 설치하지 않는다. 기존 정책 파일·저널·비용·결과 불명 이력은 그대로 보존한다. 만료된 승인 처리와 실제 활성 승인은 변경하지 않는다.

무료 로컬 합성은 정확한 POST `/character/<32hex>/render`만 기존 인증 앱으로 전달한다. 기존 영상 검증·사용자 검토·CSRF·Origin과 FFmpeg 경로를 그대로 사용하며, 외부 생성·대본·상태 요청 권한은 추가하지 않는다. 이미 닫힌 시험의 특정 작업/횟수 제한이 다른 정상 로컬 합성을 막지 않도록 한 변경이다.

# 캐릭터 이미지·주제 직접 영상 제작 및 저장 승인 재사용

## 최종 동선

`스토리로 제작`은 기존 작성 경로를 유지합니다. 새 `이미지·주제 제작`은 캐릭터/이미지 선택 → 영상 주제 입력 → 영상 견적·제작 순서이며 Claude/OpenAI의 스토리 작성·이미지 분석을 실행하지 않습니다. 캐릭터 등록과 내 캐릭터 보관도 강제하지 않습니다. 내부 schema 4 데이터는 모델 길이와 요청 순서를 검증하는 기술 실행 계획이며 AI가 작성한 스토리로 표시하지 않습니다.

직접 제작 기본값은 15초 단일 요청입니다. 영상 길이에서 30초 등 긴 길이를 선택하면 이어 만들기를 적용합니다. 별도 체크는 요구하지 않습니다. 현재 모델의 네이티브 길이 제한에 맞춰 30초는 15초 2개로 구성하며, 완료된 이전 영상의 검증된 마지막 프레임에서 다음 구간을 시작합니다. 마지막 프레임은 시각 연결을 돕는 수단이며 줄거리의 연속성을 보장하지 않습니다. 자동 유료 재시도나 견적 상향 승인은 없습니다.

## 반복 확인 제거

캐릭터 이미지 분석·주제 생성의 매번 체크해야 하던 사용 동의를 제거했습니다. 버튼 클릭은 사용자가 시작한 작업이며, 저장된 API 승인·요청당 한도·인증·키·모델 검사는 유지합니다. 한도나 승인을 매번 다시 저장하지 않습니다.

기존 오류 문구는 사용 승인/한도가 실제로 누락됐다는 뜻이 아니었습니다. 과거 결과 불명 기록이 새 작업까지 막고 있었으며 운영 설정은 이미 승인·한도·인증이 저장된 상태였습니다. 새 경로는 **이미 사용자가 명시적으로 검토한 동일한 과거 기록**만 다른 작업에 재사용합니다. 같은 작업·진행 중·미검토·변경된 결과 불명 기록은 계속 차단합니다. 과거 요청이나 비용을 삭제·0원 처리하지 않습니다.

처음 제안했던 새 불명 결과의 검토 생략을 허용하는 테스트 변경은 자동 승인 심사에서 거절돼 수행하지 않았습니다. 기존 거절 테스트는 그대로 보존하고, 이전의 정확한 검토 기록만 재사용하는 더 좁은 구현으로 변경했습니다.

## 검증 및 운영 상태

세부 숫자는 SAFE_EVIDENCE.json을 기준으로 합니다. 등록 없는 이미지/주제 스토리 경로, 새 직접 영상 경로, 기존 등록 캐릭터 경로, 저장 승인/상한, 새 불명 차단, 1366×768 / 1920×1080 브라우저를 집중 검증했습니다. 직접 제작은 Fake 영상 공급사와 합성 원본만 사용해 15초·30초 MP4까지 로컬 FFmpeg로 완주했고 텍스트 공급사 호출은 0회였습니다. AAC 패딩 약 0.021초는 30fps 한 프레임 이내로 분리해 기록합니다. 실제 유료 API 호환성이나 결과 품질이 검증됐다고 주장하지 않습니다.

TypeScript·React 빌드는 통과했습니다. 캡처는 합성 환경이며 실제 운영 캡처가 아닙니다. 기존 전체 회귀·Guard 감사·패키징·디자인 감사는 반복하지 않았습니다.

현재 운영본과 169건 데이터·키·기존 영상·백업은 새 기능 개발로 변경하지 않았습니다. 앞선 답변은 기능 정정과 질문이었으며 추가 재시작 승인으로 해석하지 않았습니다. Python 운영 반영·정상 Stop·Start와 실제 Chrome 확인은 별도 승인 대기입니다. 실제 유료 생성·SNS·배포·main/PR #35 변경은 없습니다.

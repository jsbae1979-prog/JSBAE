## 변경

YouTube 업로드 요청에 `categoryId=25`를 강제로 덮어쓰던 동작을 제거했습니다.
통합 게시 작업실, YouTube 단독 게시, 기존 고급 게시 초안에서 영상별 카테고리를 선택·저장합니다.

선택지14개: 영화·애니메이션, 자동차, 음악, 반려동물·동물, 스포츠, 여행·이벤트, 게임,
인물·블로그, 코미디, 엔터테인먼트, 뉴스·정치, 노하우·스타일, 교육, 과학·기술.
`뉴스·정치`는 YouTube의 카테고리1개(ID25)입니다. 뉴스 기사 자체의 분야 분류와 별개입니다.

새 통합/단독 게시 화면은 카테고리를 직접 선택하게 합니다. 저장한 선택은 재진입 후 유지하며,
YouTube가 대상에 포함된 경우에만 카테고리를 보내도록 합니다. Instagram·TikTok 요청에는 추가하지 않습니다.
카테고리 수정은 새로운 검토 내용으로 취급해 이전 미실행 승인을 대체합니다.
이미 전송한 영상의 정보를 변경해 재게시하는 것은 기존 중복 방지 정책이 차단합니다.

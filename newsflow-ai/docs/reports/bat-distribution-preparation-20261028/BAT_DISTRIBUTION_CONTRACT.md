# BAT 배포 계약 — 미구현 준비 자료

이 문서는 실행 코드가 아니다. 기존 보안 차단을 피하기 위한 BAT/Python 실행 경로를 제공하지 않는다. 공식 검토와 정식 실행 경계가 정리된 뒤 적용할 요구사항만 고정한다.

## 배포 레이아웃

계획 파일명 `NewsFlowAI_v1.0.0.zip`, 업데이트 `NewsFlowAI_Update_v1.1.0.zip`는 예약 명칭일 뿐 실제 산출물이 아니다. 현재 ZIP·BAT·내장 런타임은 없다.

사용자 제안의 Start/Stop/Update BAT, app(런타임·제품·React·의존성), tools(FFmpeg/FFprobe), samples, README 구조를 목표로 한다. 추가 license/source 자료와 서명된 릴리스 매니페스트가 필요하다. 운영 DB·keys·tokens·합성 테스트 DB·테스트 Guard·빌드 캐시·임시 로그·개발자 경로는 포함하지 않는다. 설치된 venv나 PyInstaller 내부 폴더를 독립 Python 런타임으로 간주하지 않는다.

## Start 계약

프로그램 기준 경로·Windows11/AMD64·정식 Python3.14.7 런타임·필수 자산 검증 후에만 기동 준비. 사용자 데이터는 프로그램 밖의 명시적으로 소유한 경로에 보관하고 기존 운영 자료 자동 발견/복사를 하지 않는다. 현재 배포 경로와 호환 여부를 따로 확인한다. 읽기 전용 설치 경로를 캐시·로그·DB 기본 위치로 쓰지 않는다.

고정된 사용자별 설정 포트를 원자적으로 예약하고 8765와 외부 bind는 거부한다. 충돌 시 오류 안내하고 멈추며 자동 port fallback은 하지 않는다. 현재 실행마다 임의 포트인 구현을 이 조건의 완료 증거로 사용하지 않는다.

기존 bootstrap·HttpOnly cookie·Origin/Host/CSRF 보호를 보존한다. HTTP 준비와 인증 준비가 확인된 뒤 현재 사용자 기본 브라우저를 연다. 토큰을 콘솔/로그/파일 경로에 기록하지 않는다. 시작 실패를 정상 준비로 표시하지 않는다. 스케줄러와 자동 유료 작업을 배포 진입점만으로 활성화하지 않는다.

## Stop 계약

현재 사용자·실행 경로·프로세스 생성 시각·인증된 실행 세션 등으로 소유권을 확인한다. 임의 PID, 프로세스명 전체, 포트 점유자 전체를 종료하지 않는다. PID 재사용과 위조 상태 파일을 거부한다. 정상 종료 요청 후 소유 서버의 수명 정리·소켓 해제·잠금 해제를 확인한다. 제한시간 초과는 미종료/결과 불명으로 기록하고 자동 강제 종료하지 않는다. 다른 Windows 사용자와 운영 프로세스는 대상으로 삼지 않는다.

## ZIP 업데이트 계약

선택한 오프라인 ZIP의 진위 검증이 데이터 쓰기/앱 종료보다 먼저다. 승인된 외부 신뢰 경로로 설치된 배포자 키/인증서와 실제 서명된 매니페스트를 사용한다. ZIP 스스로 담은 키를 곧바로 신뢰하지 않으며, SHA-256만 통과한 패키지는 거부한다. 전체 ZIP과 내부 파일 목록·크기·해시·릴리스 ID·버전·증가 순서를 서명에 결속한다. 현재 빈 certificate pin/updatesEnabled:false를 우회하는 개발 플래그를 넣지 않는다.

프로그램과 사용자 경로의 잠금 후 소유 앱 정상 종료를 확인한다. 외부 경로·절대/상위 경로·UNC/ADS/Device·링크/reparse·대소문자 중복 파일·과도한 압축/크기 등을 거부하는 압축 검증이 필요하다. 경로 문자열 검사만으로 안전을 주장하지 않는다. 사용자 DB/키/OAuth/미디어/ledger를 업데이트 payload 목적지로 허용하지 않는다.

기존 버전을 보존한 별도 staging/slot에서 내용을 검증하고 현재 포인터를 원자 전환한다. 호환 migration만 검증하며 실행 전 SQLite backup과 설정/키의 불투명 바이트 백업을 보존한다. 새 버전 건강 확인 실패는 이전 프로그램과 일관된 데이터 백업을 복원한다. 비가역 migration/소유권 불명/전원 중단 결과 불명은 자동 재시도하지 않고 journal과 수동 복구 상태를 보존한다. 기존 EXE 업데이트 PASS를 새 ZIP 경로의 성공으로 표시하지 않는다.

## 샘플·미디어·검증

외부 전달에는 rightsVerified:true 및 실제 권리 증빙이 있는 자산만 포함한다. 현재12개는 false라 배포 자격0개다. 원본/사용자 복사본은 보존한다. 외부 전달 샘플 수가 줄면 명확히 안내하고 신규12개가 포함됐다고 주장하지 않는다.

FFmpeg/FFprobe는 검증된 Windows 바이너리와 고지·정확한 대응 소스/recipe를 함께 준비한다. 소스 built/GPL 조건과 미완료 최종 확인은 그대로 유지한다. 무서명 개발 후보를 서명 제품으로 표시하지 않는다.

실제 실행 검증은 공식적으로 허용된 경로에서만 진행한다. 새 ZIP 해제·일반 사용자 기동·인증·제작·FFmpeg·정상 종료/재실행·업데이트/복구·데이터 격리를 변경 영향 범위로 검증한다. 외부 API·SNS·운영8765는 사용하지 않는다. V3 차단을 피하기 위한 대체 진입점 시험이나 보안 해제/예외/ACL 완화는 검증 방법에 포함하지 않는다.

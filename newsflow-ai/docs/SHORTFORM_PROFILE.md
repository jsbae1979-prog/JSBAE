# 숏폼 강조 옵션

기존 뉴스·대본·음성·FFmpeg·VideoProvider를 재사용한다. 새 메뉴와 새 공급사는 없다.
설정 → AI 영상 아래의 `숏폼 강조`에서 저장하며, 저장 자체는 외부 요청을 하지 않는다.

| 설정 | 기본값 | 적용 |
|---|---|---|
| 숏폼 강조 | 꺼짐 | 새로 시작한 OpenAI/Claude API 작업·대본만 |
| 목표 길이 | 30초 | 15~35초; 기존 45·60초 방식 유지 |
| 첫 훅 | 켜짐 | 15~25자, 첫 내레이션과 동일, 첫 장면 3초 이내 |
| 중앙 큰 자막 | 켜짐 | 굵은 64px, 훅 72px; 최대 2줄, 핵심어·수치 강조 |
| 카드 움직임 | 켜짐 | 느린 줌, 3초 주기 강조 표시, 자막 등장 효과 |
| 상단 출처 | 켜짐 | 저장된 언론사명 표시; 출처 연결은 옵션과 무관하게 보존 |
| 짧은 종료 | 켜짐 | 실제 발화 뒤 0.35~0.384초 여백; 목표까지 무음 채우기 없음 |
| 음성 배율 | 1.1배 | 선택한 엔진의 기존 속도에 추가 적용, 로컬 FFmpeg atempo |

## 대본·제작 계약

- 기존 검색→분석→대본 요청에 숏폼 구성을 전달한다. 훅 전용 추가 호출은 없다.
- 한 이슈를 3~4장면으로 구성하고, 배경·핵심·마무리의 밀도는 QUICK/STANDARD를 따른다.
- 목록 페이지도 자료로 쓸 수 있으나 미확인 사건·날짜·수치·최신성을 만들 수 없다.
- 대본 생성·편집·영상 제작 시 기존 구조·출처·수치·비밀정보 검사를 유지한다.
- 구독 요청과 긴 엔딩 카드는 자동 추가하지 않는다. 기존 대본 편집·검토를 사용한다.
- 옵션은 새 작업 요청, 대본 근거, 영상 스냅샷에 보존한다. 기본값을 바꿔도 기존 작업은 바뀌지 않는다.
- 15~35초 확장 길이는 숏폼 대본에서만 허용한다. 기존 로컬 대본을 API 대본으로 전환하지 않는다.
- 훅 음성이 3초 초과하거나 전체 실측 분량이 15초~목표 길이에 맞지 않으면 검토로 돌린다.
- 실패·길이 불일치 시 추가 유료 호출, 음성 재생성, Provider·voice 변경을 자동 실행하지 않는다.
- 키 유무로 ElevenLabs를 자동 선택하지 않는다. 저장된 voice ID, 비용·전송 동의·중복 방지를 유지한다.
- AI 계획에서 첫 훅을 후보로 배정할 수 있으나 실제 유료 생성·관계 검토·합성 승인은 기존 절차다.
- VERIFIED의 독립 검증 미지원/BLOCKED 정책은 그대로다.

## 검증 범위

`tests/test_shortform_profile.py`와 직접 영향을 받는 `test_video.py`,
`test_api_news_pipeline.py`만 Windows Python 3.12/3.14 CI로 확인한다.
합성 DB, Fake API/음성, 고정 로컬 자료를 사용하며 CI는 실계정과 유료 생성에 접근하지 않는다.

별도 로컬 비교 샘플은 같은 합성 뉴스와 Windows 한국어 음성을 사용한다.
기계적 코덱·해상도·길이·훅·끝 여백 검사는 사실성·사람의 음질·시청 품질 PASS가 아니다.
문장 단위 타임스탬프 안의 자막 분할은 길이 비례 추정이며 단어 단위 강제 정렬로 표시하지 않는다.

운영 데이터 migration은 추가하지 않는다. 운영 앱 재시작·실제 API 실행은 별도 승인 단계다.

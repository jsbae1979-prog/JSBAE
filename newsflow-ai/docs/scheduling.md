# 자동 제작 예약 (Phase 5E)

**홈 → 자동 제작 예약하기**, 또는 **자동 제작 → 시간을 정해 자동 제작 예약하기**로 들어갑니다.

1. 이름, 반복 방식(매일 / 요일 선택 / 한 번만), 한국 시간과 제작 조건을 정하고 **예약 저장**을 누릅니다.
2. 새 예약은 **일시 중지** 상태입니다. 안내에 동의한 뒤 **예약 켜기**를 누릅니다.
3. 앱과 PC를 켜 둡니다. 다음 실행 시각은 **KST(UTC+9)**입니다. Windows 표시 시간대와 관계없이 한국 시간을 사용합니다.
4. 최근 실행 이력에서 현재 단계와 진행률을 확인합니다. **제작 상태·해결 방법 확인**을 누르면 기존 제작 화면으로 이동합니다.
5. 완료 영상을 재생하고 게시 대기함에서 내용·출처·권리를 직접 검토합니다. 실제 게시 기능은 실행하지 않습니다.

체험 제작은 합성 뉴스 → 기본 대본 → 기본 세로 검토영상 → 로컬 게시 대기함까지 이어집니다. 실제 뉴스는 등록한 공개 RSS를 수집하지만, 대본과 최종 영상에서 반드시 사람의 확인을 기다립니다. 예약은 저장된 유료 AI 설정을 상속하지 않습니다. 유료 AI 대본·Higgsfield 자동 생성·OAuth·SNS 게시를 실행하지 않습니다. 음성은 무음 또는 저장한 PC 음성 설정만 사용합니다.

## 중지와 복구

- **일시 중지**: 앞으로의 예약만 멈춥니다. 진행 중인 제작은 별도로 **이번 제작 취소**를 누릅니다.
- **예약 해제**: 앞으로 실행하지 않습니다. 실행 이력·만들어진 영상·초안은 삭제하지 않습니다.
- 예약은 최대 50개입니다. 같은 시간·요일·제작 조건의 중복 예약은 저장하지 않습니다. 매일과 모든 요일 선택은 같은 예약으로 봅니다.
- 앱 종료 중에는 실행하지 않습니다. 다시 앱을 켜면 저장한 활성 예약을 복원합니다. 예정 시각을 90초 넘게 놓쳤다면 한 건의 미실행 이력을 남기고 다음 미래 시각으로 넘어갑니다. 지난 며칠·몇 달을 몰아서 실행하지 않습니다. 90초 이내 지연은 해당 한 건만 실행합니다.
- 다른 제작이 실행 중이거나 사람의 검토를 기다리면 새 예약은 **다른 작업 확인 필요**가 됩니다. 작업을 먼저 마친 뒤 이력에서 직접 다시 시도할 수 있습니다. 자동 재시도나 밀린 작업 큐는 없습니다.
- 중간에 앱이 종료되면 기존 제작 단계·산출물을 보존하고 중단 상태로 표시합니다. 자동으로 성공 처리하지 않습니다. 기존 작업을 확인하고 안전한 경우에만 같은 작업 번호로 직접 다시 시도합니다. 결과 불명 작업은 자동 재전송하지 않습니다.
- 수정은 앞으로의 예약에 적용합니다. 이미 생긴 실행 기록은 당시 제작 조건을 보존합니다. 실패한 실행의 재시도도 원래 조건을 사용하므로 조건을 바꾸려면 예약을 수정하고 새 실행을 기다리세요.
- 같은 기사를 다시 영상으로 만드는 것은 기존 기사별 제작 잠금으로 막습니다. 체험 뉴스는 8개이며 모두 사용한 경우 새 체험 기사가 생기지 않습니다. 기존 결과를 확인하세요.
- `migrate_data`로 DB를 다른 폴더에 **복사**하면 복사본의 활성 예약은 일시 중지됩니다. 원본은 그대로 보존합니다. 두 폴더에서 같은 예약이 동시에 실행되지 않도록 이전할 앱과 폴더를 확인한 뒤 직접 켜세요. 이 도구는 영상 파일을 옮기지 않으므로 영상 등 사용자 파일을 별도로 백업해야 합니다.

## Windows 작업 스케줄러 조사

공식 문서 확인: **2026-10-16 KST**, 아래 Microsoft 문서 모두 HTTPS GET 200. OS 작업 등록·실행은 수행하지 않았습니다.

- [schtasks /create](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/schtasks-create): ONLOGON, DAILY, WEEKLY 트리거를 지원하며 `/IT`는 지정 사용자가 로그인해 있을 때만, `/RL LIMITED`는 최소 권한으로 실행합니다.
- [Security Contexts for Tasks](https://learn.microsoft.com/en-us/windows/win32/taskschd/security-contexts-for-running-tasks): 실행 계정·로그온 방식·권한을 명시해야 합니다. DPAPI와 사용자 데이터가 현재 사용자에 묶이므로 SYSTEM 또는 다른 계정으로 바꾸면 안 됩니다.
- [StartWhenAvailable](https://learn.microsoft.com/en-us/windows/win32/taskschd/tasksettings-startwhenavailable): 놓친 작업을 나중에 시작하는 OS 설정입니다. 앱의 90초 지연 정책과 별개이며 이를 켠다고 누락된 영상을 일괄 생성하지 않습니다.

향후 사용자의 별도 동의를 받는다면, 현재 사용자·로그온 시·최소 권한으로 기존 `run.bat`을 실행하는 방식을 검토할 수 있습니다. 실제 제작 예약은 이 앱의 한 곳에서 관리하고, OS에 각 영상 제작 작업을 중복 등록하지 않는 방향입니다. 경로 인용, 작업 시작 폴더, 단일 앱 실행, 로그아웃·절전·배터리·Windows 재부팅 조건을 사용자 PC에서 검증해야 합니다. 이번 버전은 OS 작업 등록 코드를 제공하거나 자동 등록하지 않습니다. PC가 꺼져 있는 동안의 실행, 자동 켜기, 무인 유료 생성은 **NOT VERIFIED / 미지원**입니다.

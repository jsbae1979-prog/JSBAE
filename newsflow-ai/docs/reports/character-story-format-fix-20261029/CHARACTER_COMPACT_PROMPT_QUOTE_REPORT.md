## 운영 반영

변경 전 프로그램 파일·프로필의 복구 백업을 만들고 정상 Stop 종료 코드 0을 확인했다. 아래 Python 파일 3개만 반영하고 승인된 Start를 1회 실행했다. 정상 인증으로 자동 열린 사용자 Chrome에서 캐릭터 제작실을 조작했다. 추가 재시작과 인증 우회는 없다.

- `app/product/newsflow/character/kling.py`
- `app/product/newsflow/character/schema.py`
- `app/product/newsflow/character/service.py`

새 요청은 공통 상황과 해당 장면만 전달한다. 저장된 스토리·캐릭터·음성 지시는 유지하며, 전체 5장면을 각 클립마다 반복하지 않는다. 앱의 보수적인 2,000자 검사이며 Higgsfield가 공식 발표한 수치라고 주장하지 않는다.

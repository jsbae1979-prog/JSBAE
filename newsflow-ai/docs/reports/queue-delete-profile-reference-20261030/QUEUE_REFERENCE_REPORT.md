# 대기열 삭제·캐릭터 미리보기·스토리 중단 안내 보완

대기열 선택 옆에 삭제 버튼과 확인창을 추가했다. 확인하면 선택한 대기열만 목록에서 제외한다. 대기열의 원본 실행 기록·요청 식별자·승인 자료와 연결된 대본·영상·주제·비용 기록은 보존한다. 삭제한 대기열은 생성·승인·진행 명령으로 다시 실행되지 않는다. 실행 중이거나 잠긴 대기열은 삭제하지 않으며, 실패 시 선택과 확인창을 유지한다. 운영 환경의 대기열을 대신 삭제하지 않았다.

캐릭터 이미지 누락은 저장 작업을 열었다가 ‘새 작업’ 또는 ‘새 스토리 입력’으로 이동할 때 발생했다. 등록 캐릭터 상태는 남지만 저장 작업의 참조 URL과 화면의 임시 이미지 식별자가 사라져 미리보기가 비었다. 새 작업에서만 선택된 프로필의 유효한 이미지 식별자를 재사용하도록 고쳤다. 저장 작업은 기존에 보존된 참조 이미지를 계속 사용한다. 등록 파일이나 이미지 원본은 수정하지 않았다.

스토리 오류는 이미지 누락과 별개다. 읽기 전용 점검에서 최근 실패 작업은 외부 전송 전 중단 상태, 유료 시도 0, 스토리 결과 없음으로 기록되어 있었다. 요청 형식·모델 매핑은 정상이다. 점검 당시 Claude 연결 확인 기록의 24시간 유효기간이 만료되어 현재 사전 검사를 통과할 수 없었다. 과거 실패 기록에 상세 사유가 없으므로 모든 과거 실패가 같은 원인이었다고 단정하지 않는다. 연결 유효기간·비용 한도·승인 정책을 완화하거나 실제 연결 확인/생성을 재요청하지 않았다.

검증은 합성 프로필과 Fake만 사용했다. 대기열 삭제의 보존·멱등·재실행 거부·인증/Origin/CSRF·정확한 운영 경계를 검사했고, 브라우저에서는 삭제 취소/확인/실패와 두 캐릭터의 이미지 유지·전환을 확인했다. TypeScript 및 React 빌드가 통과했다. 초기 이미지 브라우저 검사의 실패는 기존 오류 응답 및 로컬 초안 요청에 대한 테스트 기대값을 수정하여 해결했다. 최종 고유 검사 결과는 SAFE_EVIDENCE.json에 기록한다.

이 변경은 Python API와 운영 로컬 쓰기 경로에 대기열 삭제 한 건을 추가하므로 운영 반영에는 정상 Stop·Start가 필요하다. 사용자의 정상 Stop·Start 1회 승인을 받은 후 아래와 같이 운영 반영했다. 실제 적용 시 현재 프로그램 및 사용자 프로필을 백업하고, 원본 DB와 백업 A/B·키·미디어를 유지하는 기존 절차를 사용한다. 유료 API·SNS·무서명 업데이트·외부 배포·PR 병합은 수행하지 않는다.

스토리 사전 검사 안내는 정확히 확인된 연결 확인 실패만 별도 코드로 처리하고, 그 외 거절은 일반 설정 안내를 유지한다. 새로운 실패에 명시적인 미전송 근거가 있을 때만 유료 요청 미전송을 표시한다. 과거 기록을 수정하거나 이전 실패를 현재 실패처럼 재사용하지 않는다.

최종 집중 검사: 신규 40 PASS, 기존 영향 범위 96 PASS, 최종 FAIL/ERROR 0. 중복 실행된 동일 검사는 한 번만 집계했다. 전체 회귀·패키징·보안 재감사는 반복하지 않았다.

운영 반영 소스 `1e39ab8e42b9f6efba0603b5be7b056f72c50e30`. 정상 Stop 1회(코드 0), Start 1회. Chrome 열기 요청 수락, 포트 18768, PID 31076. 47개 테이블과 기사 169건 불변, 프로필 파일 125개 보존, 원본 DB와 백업 A/B·보안 설정 불변. 백업 126개 항목과 이전 프로그램 파일은 로컬 비공개 경로에 보관했다. 토큰·키·운영 DB·미디어를 저장소에 넣지 않았다.

현재 UI 구현·합성 검증·승인된 운영 반영은 완료했다. 사용자 Chrome의 최종 시각 확인은 대기 중이다. 스토리 실사용은 Claude 연결 확인 상태를 정상 갱신한 뒤 별도 사용자 실행으로 검증해야 하며, 이번 작업에서 공급사 호출을 수행하지 않았다.

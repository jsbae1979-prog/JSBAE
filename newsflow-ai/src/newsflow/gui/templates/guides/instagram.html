1. Instagram 계정 만들기

  1. Instagram 웹이나 공식 앱에서 가입합니다. 기존 계정이 있다면 그대로 로그인할 수 있습니다.
  2. 프로필의 사용자 이름과 복구 수단을 확인하고 2단계 인증을 설정합니다.
  3. 직접 게시만 할 경우 NewsFlow AI용 Meta 앱·Facebook Page·인증 중계는 필요하지 않습니다. 앱 연동을 원할 때만 아래 추가 준비를 진행하세요.

완료 확인: 자신의 프로필에 로그인하고 게시물 만들기 메뉴가 보입니다.

2. 직접 업로드하기 · 가장 간단한 시작

  1. NewsFlow AI에서 완성 MP4를 내려받아 영상·음성·자막·출처·사용 권리를 확인합니다.
  2. Instagram 웹의 만들기(＋)에서 영상을 선택합니다. 웹에서 해당 기능이 제공되지 않으면 공식 모바일 앱의 Reels 만들기를 사용합니다.
  3. 세로 화면 자르기·커버·설명·태그를 확인합니다. 음악이나 사람의 얼굴·목소리를 사용할 권리, 해당하는 AI 콘텐츠 표시도 검토합니다.
  4. 계정과 공개 범위를 확인한 뒤 직접 공유합니다. 공개 프로 계정은 게시물이 외부에 공개될 수 있으므로 테스트 영상도 신중히 선택하세요.

완료 확인: 프로필의 게시물/Reels에서 실제 재생을 확인합니다. 직접 게시한 결과가 NewsFlow AI 이력에 자동 반영되는 것은 아닙니다.

3. NewsFlow AI 연결 준비 · 운영자 설정 필요

현재 구현은 Facebook Login for Business + Page 연결 Instagram 프로 계정 방식입니다. Instagram Login 방식의 앱·토큰과 섞어 사용하지 않습니다. 연결 코드와 인증 중계 코드는 있지만 실제 배포·Meta 로그인은 미검증입니다.

  1. Instagram 설정에서 프로페셔널 계정(비즈니스 또는 크리에이터)으로 전환합니다. 공개 범위와 계정 기능 변화를 먼저 확인하세요.
  2. 본인이 관리하는 Facebook Page를 만들거나 기존 Page를 선택하고 Instagram 계정을 연결합니다. 로그인할 Facebook 사용자가 해당 Page에서 콘텐츠 작성 또는 필요한 관리 권한을 갖고 있어야 합니다.
  3. 운영자에게 아래 앱·인증 서버 준비를 요청합니다. 서버가 없다면 현재는 직접 업로드 경로를 이용할 수 있습니다.
운영자용 Meta 앱·인증 서버 준비
  1. Meta for Developers에서 지원되는 앱을 만들고 Facebook Login for Business와 Instagram API with Facebook Login을 구성합니다.
  2. 사용자 토큰 구성에서 instagram_basic, instagram_content_publish, pages_show_list, pages_read_engagement 권한을 준비합니다.
  3. 개발용 앱의 역할·테스트 계정 접근 조건을 확인합니다. 외부 사용자에게 제공하려면 앱 검수·고급 액세스·비즈니스 인증 등 Meta가 요구하는 조건을 충족해야 합니다. 앱 생성만으로 권한이 승인되지는 않습니다.
  4. 유효한 인증서가 있는 HTTPS 인증 중계 서버를 배포하고 정확한 https://인증도메인/oauth/callback 주소를 등록합니다. 기존 배포 문서는 배포 ZIP의 docs/INSTAGRAM_AUTH_RELAY.md입니다.
  5. App ID·로그인 구성 ID·App Secret을 서버에서 안전하게 관리합니다. App Secret은 Windows 앱에 입력하거나 배포하지 않습니다. 인증 코드·토큰이 웹 서버 로그에 남지 않도록 구성합니다.

인증 중계는 계정 연결용입니다. 영상 저장 서버가 아니며, 현재 게시 코드는 MP4를 Meta로 직접 전송합니다. 서버 배포·도메인·인증서 준비는 프로그램 실행만으로 자동 완료되지 않습니다.

  1. NewsFlow AI의 설정 → 게시 계정 → Instagram → 로그인 연결 설정에서 운영자가 제공한 HTTPS 주소와 Meta 앱 ID를 저장합니다. 토큰·App Secret은 입력하지 않습니다.
  2. Meta 로그인과 권한 확인에 동의하고 Facebook으로 Instagram 연결을 누릅니다. 공식 로그인 화면에서 권한을 검토합니다.
  3. 연결 가능한 Page와 Instagram 계정을 확인하고 게시할 계정을 선택합니다. 앱에서 연결 상태를 새로고침합니다.

완료 확인: 앱에 원하는 Instagram 계정이 게시 계정으로 확인됩니다. 연결 주소 저장과 실제 계정 연결 성공은 별개입니다.

4. 앱에서 전송·게시하기

  1. 완성 MP4와 설명을 검토하고 Instagram 대상 계정을 선택합니다. 출처·사용 권리·AI 표시를 확인해 검토 내용을 저장합니다.
  2. 이번 영상의 외부 전송을 승인합니다. 전송 완료와 공개 게시 완료는 다른 상태입니다.
  3. 처리 상태를 확인하고 게시 준비가 끝난 뒤 공개 게시를 별도로 승인합니다. YouTube의 비공개 업로드와 같은 옵션이 있다고 가정하지 마세요.
  4. 게시 ID·결과와 Instagram 프로필을 확인합니다. 결과 불명이나 처리 대기 중에는 새로 업로드하지 마세요.

5. 막혔을 때

공식 로그인 연결 준비 필요라고 나와요
인증 중계 HTTPS 주소와 앱 설정이 필요합니다. 주소를 임의로 입력하지 말고 운영자에게 확인하세요.
선택할 Page나 Instagram 계정이 없어요
프로 계정 전환·Page 연결·Facebook 사용자의 Page 권한·앱 접근 권한을 확인하세요. 개인 계정을 이 API 경로로 바로 연결할 수는 없습니다.
로그인·권한 오류가 나요
운영자가 등록한 redirect 주소, 앱 역할·검수 상태, 만료·철회된 권한을 확인해야 합니다. YouTube의 JSON이나 인증 방식을 대신 사용하지 마세요.
영상이 처리 중이거나 결과 불명이에요
기존 작업의 상태와 Instagram 프로필을 먼저 확인하세요. 반복 전송은 중복 게시를 만들 수 있습니다. 오류 제보에 토큰·로그인 링크를 넣지 마세요.

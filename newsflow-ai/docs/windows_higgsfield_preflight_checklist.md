# Windows 11 Higgsfield 최초 실행 사전 점검

Phase 5D.1 / 2026-10-16 KST. 이 체크리스트는 유료 생성 승인이 아니다. 실제 계정·유료 호출은 이번 개발에서 검증하지 않았다.

1. 프로그램을 종료하고 `%LOCALAPPDATA%\NewsFlowAI` 전체를 백업한다. DB뿐 아니라 `ai-clips`, outputs, 설정·DPAPI 파일을 보존한다. 다른 Windows 사용자에게 키 파일을 공유하지 않는다.
2. `feat/newsflow-phase5d1` 변경을 확인한다. 기존 미커밋 작업을 보존하고 `git pull --ff-only`만 사용한다. main 및 기존 PR은 병합하지 않는다.
3. 기존 `setup.bat`과 `run.bat`으로 Python 3.12, FFmpeg/ffprobe, 한국어 글꼴, 127.0.0.1:8765를 확인한다. 포트 충돌이면 이전 앱을 종료하며 임의 외부 바인딩/포트 변경은 하지 않는다.
4. 처음에는 AI 영상 공급사를 **사용 안 함**으로 유지한다. 기본 로컬 FFmpeg 영상과 이전 대본·클립·영상 목록이 남아 있는지 확인한다.
5. 설정 → AI 영상 → **비용 없이 사전 점검**을 누른다. 키가 없거나 미승인이면 FAIL 안내가 정상이다. 검사 자체는 API 요청·비용 예약을 하지 않는다. FFmpeg/ffprobe 실행과 로컬 키 형식 확인만 한다.
6. 향후 실제 연결을 별도 승인한 경우에만 키를 본인 PC의 DPAPI 저장소 또는 환경변수로 설정한다. 키를 채팅·Git·스크린샷에 붙이지 않는다. ID:비밀값 형식 확인은 실제 인증 성공이 아니다.
7. [공식 문서 재검증](reports/phase5d1_higgsfield_verification.md)을 보고 선택 모델의 경로·길이·9:16·해상도·기본 음성 옵션·실제 단가·계정 동시성·잔액을 확인한다. 앱 한도는 사용자 단가에 근거한 추정치이므로 공급사 지출 제한도 별도로 설정한다.
8. 결과 불명 요청이 있으면 공급사 기록을 먼저 확인한다. 새로 누르거나 DB 비용 행을 지우지 않는다. 기존 요청 번호가 있는 항목은 조회/다시 받기를 우선한다. 408·429도 자동 재전송되지 않는다.
9. 실제 유료 호출 전 **호출 횟수·모델·최대 비용·전송할 내용**에 대한 별도 승인을 받는다. 이 체크리스트를 완료했다고 호출을 실행하지 않는다.
10. 별도 승인 후 최초 생성 시 요청 ID, 입력 옵션, 공급사 실제 청구, 내려받은 파일, 한국어 자막·음성·브라우저 재생을 사람이 대조한다. 청취·시청 평가는 자동 테스트와 구분해 기록한다. SNS 업로드/OAuth는 계속 차단한다.

기록 양식: 실행일시(KST), Windows/Python/FFmpeg 버전, 검토 커밋, 로컬 점검 결과, 기존 데이터 보존 여부, 미해결 항목, 사람 평가. 키·서명 URL·개인정보는 적지 않는다. 사용자 PC 결과는 현재 **NOT VERIFIED**다.

# Kling O3 Standard 5개 장면 생성 및 Chrome 검토

확인일: 2026-10-30. 브랜치: `codex/newsflow-bat-distribution-prep`.
운영 프롬프트 코드: `885c7b2d4d75a92fcbee7be89a04e91e95ab71bf`.

## 결과

사용자가 승인한 **US$3.36, Kling O3 Standard, 30초, 음성 포함** 설정으로 5개 장면을 최초 생성했다. **5개 성공·저장 / 실패 0 / 결과 불명 0 / 유료 재시도 0**. 사용자 Chrome에서 1~5번을 차례로 음소거 없이 끝까지 재생했고 동영상 오류는 없었다. Claude 추가 호출, 운영 재시작, 제품 코드 변경은 없다.

최종 합성은 하지 않았다. 생성 및 재생 성공과 별개로, 조연의 외형·종류가 일부 장면에서 달라지는 연결 차이가 관찰됐다. 사용자는 장면별 화면·상황이 달라 하나의 30초 쇼츠로 이어지지 않는다고 판정했다. 콘텐츠 연속성 검토는 불합격이며 이를 검토 완료 처리하지 않았다. 음성 자체의 세부 품질 판정은 별도다.

**최종 판정: CONDITIONAL — 생성·저장은 성공, 콘텐츠 연속성 인수는 실패.**

## 견적 만료와 최초 제출의 구분

처음 UI에서 생성 승인을 실행했을 때 기존 견적이 15분을 지나 로컬 사전 검사에서 거절됐다. 공급사 생성 요청·핸들이 없는 상태를 확인하고 만료 견적 사본을 보존했다. 동일한 작업·프롬프트·설정으로 공식 견적만 한 번 갱신했으며 금액은 US$3.360으로 같았다. 승인된 금액이 유지된 것을 Chrome에서 확인한 뒤 최초 유료 제출을 실행했다.

새 견적의 5개 장면은 모두 `attempt=1`이고 각각 최초 요청 핸들 1개만 갖는다. 기존 실패 작업이나 실패 장면을 재시도하지 않았다. 견적 갱신은 영상 재생성과 구분한다. 가격 변경·자동 재요청·임의 비용 상향은 없다. 실제 계정의 이번 거래 명세는 별도 조회하지 않았으므로 US$3.36을 실제 확정 청구액으로 표시하지 않는다.

## 보존 확인

새 읽기 전용 보존 검사 1 PASS / 0 FAIL / 0 ERROR. 기사 169건·47개 DB 테이블, 변경 테이블 0개. 보호 파일 26개 및 ACL, 원본 DB·백업 A/B, 기존 유료 작업 기록, 기존 실패 5건 모두 불변이다. 새 작업의 승인·최초 요청·완료 클립 저장 외에 다른 제작 자료를 변경하지 않았다. 보안 설정, 자동화, SNS, 무서명 업데이트, main·PR #35, 외부 배포는 변경하지 않았다.

Chrome 캡처 5장·MP4·개인 스토리·참조 이미지·요청 ID는 로컬에만 보존한다. GitHub에는 비민감 결과만 기록한다. 신규 전체 회귀·패키징·보안 감사는 실행하지 않았다.

## 사용자 검토 후 개발본 최소 보완

운영에 적용된 요청은 공통 상황과 각 장면의 자기 행동만 전달해, 이전 장면의 상태와 공통 연출을 이어받지 못했다. 사용자의 요구는 6초짜리 독립 영상 5개가 아니라 같은 등장인물·공간에서 이어지는 30초 상황극이다.

개발본은 새 견적에만 다음 지침을 적용하도록 보완했다.

- 5개 클립을 하나의 영화로 명시하고 종·얼굴·의상·목소리·세트·소품·조명·시간의 동일성을 요구한다.
- 첫 장면의 setup을 모든 요청에 같은 비연기 문맥으로 전달한다.
- 직전 장면의 행동은 이미 완료된 상태로 전달하고, 이를 반복하지 않고 그 결과에서 이어가도록 한다.
- 중간 장면은 다음 행동으로 이어지고 마지막 장면만 같은 사건을 마무리하도록 한다.
- 앞으로 새 Claude 스토리를 만들 때도 하나의 장소·연속된 시간과 구체적 조연 외형의 일관성을 요구한다. 이번에는 Claude를 호출하지 않았다.

새 요청 계산 결과는 1,607 / 1,829 / 1,822 / 1,873 / 1,940자다. 기존 2,000자 검사를 유지하며 원본 행동을 자르지 않았다. 합성 집중 검사 **40 PASS / 0 FAIL / 0 ERROR**. 초기 개발안의 공통 문구가 길어 현재 스토리의 오프라인 계산이 제한을 넘었으나, 중복 일반 문구만 줄여 최종 계산이 통과했다. 외부 전송은 없었다. 최대 길이 필드 조합이 제한을 넘는 경우에는 내용을 몰래 생략하지 않고 기존 방식대로 견적 전 차단한다.

이 보완은 **개발본에만 적용**했으며 운영 파일·프로세스·기존 스토리·이번 5개 성공 결과를 변경하지 않았다. 기존 승인이나 견적에 새 요청을 끼워 넣지 않는다.

### 남은 한계와 다음 제작 조건

문장 지침만으로 실제 조연의 외형·목소리·배경이 동일하게 생성된다고 보장하지 않는다. 현재 제품은 매 장면에 같은 주인공 PNG를 전달할 뿐, 조연·공간의 확정된 시각 자료나 이전 클립 마지막 프레임을 다음 클립에 연결하지 않는다. 따라서 이번 수정만으로 품질 문제가 해결됐다고 판정하지 않는다.

[Higgsfield 공식 O3 규격](https://open.higgsfield.ai/models/kling-video/o3/image-reference/api-reference)은 여러 참조 이미지와 첫/마지막 프레임 항목, 3~15초 길이를 명시한다. 그러나 이 제품의 연속 장면 입력으로 사용하려면 참조 자료의 역할·파일 소유권·새 견적·순차 생성 계약을 검증해야 하며 이번 작업에서 해당 기능이나 실제 호환성을 구현·검증했다고 주장하지 않는다. 강한 시각적 연결이 필요한 다음 제작은 고정된 조연·공간 기준과 연속 프레임 연결을 먼저 준비하는 것이 적절하다. 유료 재생성·운영 반영·재시작은 수행하지 않았다.

# 한국어 음성 청취 확인표 (사람이 직접 듣고 기록)

이 확인표는 **사람이 실제로 들은 결과**만 기록합니다. 자동 테스트와 CI 검증 도구는 "비무음 WAV가 생성되었는지"와 "MP4가 재생 가능한지"만 확인하며, 어떤 자동 절차도 PASS를 기록하지 않습니다. 기록은 `설정 → 음성과 자막`의 **청취 결과 기록** 양식으로 저장하며(데이터 폴더 `voice-listening\listening-<id>.json`, 최근 50건 보관), 부정확 항목이 하나라도 있으면 PASS로 저장할 수 없습니다. 음성 이름·속도 외의 개인 정보나 로그는 적지 마세요.

## 1. 식별

| 항목 | 기록 |
|---|---|
| 음성 이름 · culture | 예: Microsoft Heami Desktop · ko-KR |
| 속도 · 문장 사이 쉼 | 예: 0(보통) · 250ms |
| 미리 듣기 파일 이름 | `preview-<id>.wav` (화면의 재생 파일) |
| Windows 빌드 | `winver` 표시값 |

## 2. 항목별 청취 (정확 · 부정확 · 불명)

미리 듣기 문장: 「안녕하세요. 뉴스플로 음성 미리 듣기입니다. 2026-10-15 14:30 기준 KOSPI는 3.5% 올랐고, AI 기업 매출은 $1,250,000입니다.」 화면의 **읽기 형태** 문장과 들리는 소리를 비교합니다.

| 항목 | 들어야 할 것 | 판정 |
|---|---|---|
| 숫자 | 연도 "이천이십육", 큰 수 "백이십오만", 소수 "삼점오", 단위 수사가 자연스러운지 | 정확 / 부정확 / 불명 |
| 날짜·시간 | "시월 십오일", "십사시 삼십분"으로 읽는지 | 정확 / 부정확 / 불명 |
| 영문 | 글자 읽기 "에이아이", 발음형 "코스피", 남아 있는 영단어를 한국어 음성이 어떻게 처리하는지 | 정확 / 부정확 / 불명 |
| 쉼 | 문장 사이 쉼이 설정값(0·150·250·400·600ms)과 비슷하게 들리는지 | 정확 / 부정확 / 불명 |
| 속도 | -3 / 0 / +3에서 각각 들었을 때 뉴스 낭독으로 무리가 없는지 | 정확 / 부정확 / 불명 |
| 길이 | 실제 재생 길이가 화면의 예상 길이와 ±30% 안에 있는지 | 정확 / 부정확 / 불명 |
| 명료도·음량·잡음·끝 잘림 | 발음이 뭉개지지 않고 음량이 일정하며 잡음이 없고 마지막 음절이 잘리지 않는지 (장면마다 0.35초 꼬리를 보장) | 정확 / 부정확 / 불명 |
| 자막 동기 | 완성한 30·45·60초 MP4에서 장면별 음성 시작과 자막 전환이 ±0.5초 안에 맞는지 | 정확 / 부정확 / 불명 |

## 3. 종합 판정

| 판정 | 뜻 |
|---|---|
| PASS | 모든 항목이 정확. 부정확 항목이 하나라도 있으면 선택할 수 없음 |
| FAIL | 부정확 항목이 있어 이 음성·설정으로는 제작하지 않음 |
| NOT VERIFIED | 아직 듣지 않았거나 판단을 보류함 (기본 상태) |

메모(500자 이하) · 청취자 · 일시(앱이 UTC로 자동 기록)

## 4. 참고

- 앱은 설치된 SAPI 음성 중 `ko-*` culture만 제공하며 다른 언어 음성으로 대체하지 않습니다. 목록에 없으면 무음 검토영상으로 제작하고 이 확인표는 NOT VERIFIED로 둡니다.
- 읽기 형태 변환(숫자·날짜·단위·약어)은 음성에 전달되는 문장에만 적용됩니다. 자막·대본·예상 길이는 원문 그대로입니다.
- 대본의 도입(hook)·요약·마무리 문장은 읽지 않으며, 장면 내레이션만 음성으로 만듭니다.

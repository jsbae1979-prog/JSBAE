# 뉴스 이미지 제목·캡션·게시 후 성과 비교

2026-11-01. 사진 중심 피드 편집 기능을 재사용한 무료 개선.

## 변경 결과
- 제목 후보: 현재 편집 제목, 저장 제목, 기사 원제, 요약 첫 문장에서 중복을 제외한 최대 3개를 비교한다. 저장된 문구만 사용하며 새 사실이나 질문형 문구를 만들지 않는다. 후보가 부족하면 있는 문구만 표시한다.
- 캡션 구성: 첫 문장, 핵심 사실, 독자에게 중요한 점, 선택 질문을 별도로 편집하고 무료로 캡션에 적용한다. 긴 원문은 임의로 잘라 넣지 않는다. 초안/새 버전에 구성 정보와 캡션을 저장하고 다시 연다.
- 게시 후 성과: 실제 Instagram 이미지 게시물의 버전, 게시/측정 시각, 도달, 저장, 공유, 팔로우를 사용자가 입력한다. 미확인은 빈 값이며 0과 구분한다. 반응/도달 비율과 경과 시간을 보여준다. 실제 게시 승인이나 SNS 조회를 실행하지 않는다.
- TOP별 독립 저장, 기존 이미지/캡션 버전 보존, 동일 성과 중복 저장 방지, 수정 충돌 확인을 유지한다.
- 새 POST는 두 actions 카탈로그와 운영의 정확한 로컬 경로에 등록했다. 인증·Origin·CSRF·유료 실행 차단은 유지한다.

## 캡처와 한계
캡처는 합성 뉴스·합성 도형 이미지·가상 성과만 포함한다. 운영 DB·키·사진은 포함하지 않는다.

성과는 사용자 직접 입력 자료이며 플랫폼 검증값이 아니다. 동일 기간·비슷한 독자층끼리 비교해야 하며 디자인의 인기도 상승을 보장하거나 인과관계를 판정하지 않는다. 자동 SNS 동기화·AI 신규 제목 생성·실제 게시는 추가하지 않았다. 운영 반영 결과는 별도 기록한다.

뉴스·이미지·캐릭터의 기본값 저장 키를 분리했다. 새 이미지·캐릭터 작업은 모델·입력·출력 옵션과 가격 근거 상태를 지문으로 고정한다. 기존 작업은 소급 변경하지 않는다. 이미지 기본값 변경은 다른 모드에 반영되지 않는다. 뉴스 AI 영상 기본값 저장은 생성 계획이나 유료 요청을 만들지 않는다.

기존 뉴스 이미지 피드 메뉴를 보존하면서 이미지 제작 메뉴를 추가했다. 고급 참조 입력은 접을 수 있다. 키 미등록·실제 연결 미검증·총액 미확정·현재 작업 고정 여부를 해당 행동 근처에 표시한다. 참조 기반 생성을 지원하는 것처럼 표시하지 않는다.

- 캐릭터: Seedance reference-to-video의 기존 검증된 부분집합만 유지한다. 뉴스용 text-to-video 모델을 캐릭터 참조 지원 모델로 표시하지 않는다.
- 실제 계정·잔액·단가 조회는 하지 않았다. 이미지 예상 총액은 미확정으로 표시한다. 공식 견적·사용량·청구액의 구분과 기존 승인 정책을 유지하며 추측 금액을 만들지 않는다.
- 캐릭터 새 작업은 기존 사용자별 Higgsfield 키 저장소를 사용한다. 이전 작업의 자격증명 경로는 유지하고 새 작업에서 환경변수 키로 자동 전환하지 않는다.

기존 CSRF·Origin·CSP·유료 승인·결과 불명 재요청 차단을 유지했다. 업로드 허용 범위는 새 이미지 초안 경로에 한정하고 기존 크기·파일 수 제한을 적용했다. 입력 이미지는 형식·크기·해상도를 확인하고 메타데이터를 제거해 사용자 데이터 자산 경로에 저장한다. 경로 탈출·링크·무결성 불일치를 거부한다. 검토 후 재사용해도 사용자의 기존 장면 선택을 덮어쓰지 않는다.

1. TikTok 계정 만들기

  1. TikTok 웹이나 공식 앱에서 가입합니다. 서비스의 연령·지역별 이용 조건을 확인하고 본인의 연락처로 인증합니다.
  2. 사용자 이름·프로필·공개 범위·복구 수단을 설정합니다. 가능한 보안 설정에서 2단계 인증을 켭니다.
  3. 계정 종류와 사용할 음악의 이용 조건을 확인합니다. 계정 생성과 개발자 앱 등록은 다른 절차입니다.

완료 확인: 자신의 프로필에 로그인하고 업로드 또는 만들기 기능을 사용할 수 있습니다.

2. 직접 업로드하기 · 현재 사용할 경로

NewsFlow AI의 TikTok 실계정 연결·외부 게시 기능은 아직 비활성입니다. 완성 MP4는 TikTok에서 직접 업로드할 수 있습니다. 개발자 앱이나 API 키는 필요하지 않습니다.

  1. NewsFlow AI에서 MP4를 내려받아 재생하고 영상·음성·자막·사실·출처·사용 권리를 확인합니다.
  2. TikTok 웹의 업로드 또는 공식 앱의 만들기(＋) → 업로드에서 MP4를 선택합니다. 메뉴 위치는 웹·앱 버전에 따라 다를 수 있습니다.
  3. 설명·커버·시청 대상, 댓글·듀엣·이어붙이기 허용 여부를 확인합니다. 사용할 수 있는 옵션은 계정에 따라 다릅니다.
  4. 음악 이용 권리, 광고·브랜드 관계와 해당하는 AI 생성 콘텐츠 표시를 확인하고 게시합니다. 지원되는 경우 먼저 본인만 보기로 확인할 수 있습니다.

완료 확인: TikTok 프로필에서 영상·공개 범위·재생 상태를 확인합니다. 직접 업로드한 기록은 NewsFlow AI 게시 이력에 자동 등록되지 않습니다.

3. 앱 연동은 아직 준비 단계입니다

현재 계정 연결·실제 업로드 불가. Desktop Login Kit의 연결·계정 확인·인증 갱신·해제와 기존 게시 서비스 연결 코드를 구현했습니다. 합성 계정 검증이며 실계정 인증·운영 게시 활성화는 별도 검토가 필요합니다. 키 입력이나 설정 변경만으로 활성화할 수 없습니다.

향후 연동에 필요한 준비와 제한
  1. TikTok for Developers에서 앱 용도와 이용 대상이 Content Posting API 정책에 적합한지 먼저 확인합니다. 개인·팀 내부 계정만을 위한 업로드 도구는 Direct Post 심사에 부적합할 수 있습니다.
  2. 정책 적합성이 확인되면 개발자 앱에서 Desktop 플랫폼과 Login Kit을 준비하세요. NewsFlow AI의 설정 → 게시 계정 → 추가 플랫폼 → TikTok에서 Client key·Client secret·콜백 포트를 등록할 수 있습니다. 비밀값은 Windows 현재 사용자 보호 저장소에 보관합니다. 앱 정보 저장만으로 실제 로그인은 활성화되지 않습니다.
  3. 계정 확인에는 user.info.basic, Direct Post에는 video.publish 권한과 해당 앱 심사가 필요합니다. Desktop redirect는 화면에 표시된 정확한 127.0.0.1 주소·포트·경로로 등록하세요. 포트 자동 선택은 TikTok의 Desktop wildcard 포트 정책을 사용합니다. 미심사 앱에는 공개 범위·사용자 수 제한이 있을 수 있습니다. 정확한 현재 조건은 TikTok에서 확인해야 합니다.
  4. 실행 직전에 계정이 허용하는 공개 범위·길이·상호작용 조건을 확인하고 음악·브랜드 동의와 AI 표시를 처리해야 합니다. NewsFlow AI에서는 TikTok 무인 예약 게시를 지원하지 않습니다.

공용 앱의 Client secret을 소스나 배포본에 포함하면 안 됩니다. 앱 심사·배포 비밀값 관리·실제 Windows 검증과 별도 운영 활성화 전까지 연결 버튼은 비활성입니다. 정책을 우회하는 자동 로그인·브라우저 업로드 도구를 사용하지 않습니다.

4. 게시 완료 확인

현재는 위의 직접 업로드 절차를 사용하세요. NewsFlow AI의 합성 테스트 결과나 계정 준비 화면을 실제 TikTok 게시 성공으로 판단하지 마세요. 실제 연결·권한·게시 검증은 미완료입니다.

5. 막혔을 때

NewsFlow AI에서 연결 버튼이 비활성이에요
앱 설정 등록과 실제 로그인 활성화는 다릅니다. 현재는 실제 인증 차단 상태이므로 직접 업로드를 사용하세요. 환경변수나 동의 선택으로 해제되지 않습니다.
TikTok 웹에 업로드 메뉴가 없어요
로그인 상태·계정 이용 제한·현재 지원 지역을 공식 도움말에서 확인하세요. 공식 모바일 앱의 업로드 메뉴도 확인할 수 있습니다.
음악·영상이 제한되거나 게시가 보류돼요
TikTok의 계정 알림과 콘텐츠·음악 권리·AI 표시 정책을 확인하세요. 같은 영상을 반복 업로드해 심사를 우회하지 마세요.

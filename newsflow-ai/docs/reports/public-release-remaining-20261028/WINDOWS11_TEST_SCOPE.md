# Windows 11 신규 사용자 검증 범위

2026-10-28 현재 PC는 `Windows 11 Pro 10.0.26300 / build26300`다.
읽기 전용 세션 조회에서는 기존 운영 console 세션1개만 확인했다.
별도 승인된 신규 사용자 로그인 세션/깨끗한 Windows11 테스트 VM·PC와
그 사용 자격증명이 제공되지 않았다. 새 로컬 계정 생성, 운영 세션 전환,
설치 교체, OS 배율/방화벽/백신 변경을 수행하지 않았다.

따라서 다음은 **이번 Windows11 신규 실행 결과가 아니다**.

| 항목 | 상태 | 근거/범위 |
|---|---|---|
| 실제 Windows11 새 일반 사용자 신규 설치·최초 실행 | NOT VERIFIED | 운영 환경과 분리된 새 Win11 사용자 환경 미확보 |
| 그 사용자의 DB/설정 생성·샘플12 표시·종료/재실행 | NOT VERIFIED | 현재 운영 profile을 테스트하지 않음 |
| 두 실제 Win11 SID 사이 DB/API/DPAPI·동시 포트 | NOT VERIFIED | Windows Server의 실제 SID2개 격리 PASS를 재사용하되 OS11로 확대하지 않음 |
| 실제 OS DPI100/125/150/200% | NOT VERIFIED | 운영 세션 배율 변경 없음 |
| 기존 Windows11 로컬GUI12화면·샘플MP4 3개 | 기존 PASS 재사용 | 기존 검증 범위만 유지, 신규 설치/이번 실행으로 합산하지 않음 |
| 기존 Windows Server 실제 표준 사용자2개 격리 | 기존 PASS 재사용 | CI40644408628. 개인 키/실제 계정 자료 없이 합성 endpoint로 검증 |
| 기존 한국어 오프라인 SAPI | 기존 PASS 재사용 | 실제 유료 TTS 호출 없음 |

신규 설치를 완료로 인정할 환경은 기존 운영 앱이 없는 별도 Windows11
테스트 PC/VM 또는 명시적으로 제공된 별도 테스트 사용자 세션이다.
그 환경에서 테스트용 합성 profile/빈 DB/무키·무OAuth/별도 포트로 실행하고,
현재 제품 보안 경계를 유지해야 한다. 운영 사용자를 로그아웃시키거나
운영 profile을 리디렉션하는 방법을 대안으로 사용하지 않는다.

이번 새 설치/업데이트 실패 주입은 오직 일회용 Windows Server CI에서
수행한다. Server CI 성공을 Windows11 신규 사용자 실제 설치 성공으로
대체하지 않는다. Windows11 전체 신규 설치 조건은 미검증으로 남는다.

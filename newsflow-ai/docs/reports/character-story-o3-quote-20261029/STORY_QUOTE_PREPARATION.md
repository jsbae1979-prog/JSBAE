# 현재 캐릭터 스토리 생성 및 O3 견적 준비

2026-10-29. 사용자는 현재 Chrome의 캐릭터와 주제로 스토리를 생성하고 Kling O3 Standard·30초·소리 켜기 견적까지만 확인하도록 승인했다. 영상 생성은 견적 확인 후 별도 승인이다.

## 확인된 초안 오류와 수정

실제 Chrome 입력 주제는 두 줄이다. 기존 공통 clean_text는 줄바꿈을 제어문자로 거부하므로 `/character`의 로컬 초안 생성이 422로 끝나 Claude에 도달하지 않았다. 선택한 O3 Standard·30초·6초×5·소리 켜기·1080p 출력·편당 5/일일 10 USD 조합은 유효하다. 실제 선택 자산은 10MB 제한 이내이며 키·쿠키·토큰을 읽지 않고 로컬 참조 해시만 확인했다.

주제 전용 clean_topic으로 정상 CR/LF/TAB만 공백 처리했다. 일반 clean_text의 보호, 원문 길이, 키 패턴 및 다른 제어문자 거부는 유지한다. 저장된 기존 주제는 변경하지 않는다. UI 요청 식별도 같은 정규화를 적용해 줄바꿈만 바꾼 동일 불명 요청이 새 요청으로 풀리지 않도록 했다.

실제 route와 service를 사용하는 합성 검사 30 PASS, Node 요청 식별 검사 9 PASS, TypeScript·최종 Vite 빌드 PASS다. 이 증거는 실제 공급사 호출 성공이 아니다. 운영 반영·추가 재시작·Claude/Higgsfield 호출은 아직 하지 않았다.

## 남은 실제 실행 경계

현재 운영 실행기는 로컬 초안 저장과 기존 스토리의 공식 영상 견적을 제공하지만 새 Claude auto-story 요청은 허용하지 않는다. 과거 시험 승인은 이미 종료됐고 K3·15초·무음 조건이어서 이번 O3·30초·소리 켜기에 재사용할 수 없다.

현재 주제·참조·선택 해시에 묶인 별도 스토리 전용 수정안을 로컬 검토용으로 준비 중이다. 기존 Claude writer와 월 예산/인증/미결 요청 검사를 재사용하며, PNG를 Claude에 전송하지 않는다. 스토리 보수 예약 상한 USD 0.25와 과거 보수 예약 USD 3.65, 기존 총 상한 USD 4.50을 유지하고 영상 submit/check/fetch 및 다른 공급사 권한은 열지 않는 범위다.

자동 승인 심사가 개발 checkout의 외부 AI 실행 경계를 바꾸는 코드 반영에 별도 구체적 승인이 없다는 이유로 거절했다. 실제 소스에 이 실행 통로를 적용하거나 우회·재시도하지 않았다. 해당 코드·정확한 로컬 승인 설정의 운영 반영과 정상 Stop·Start는 사용자 추가 승인을 받은 뒤 처리할 항목이다.

현재 결과: 스토리·공식 견적 NOT EXECUTED. 영상 생성 0회. 원본 169건·기존 키·미디어·백업·운영 서버는 이 작업에서 변경하지 않았다.


## 구체적 추가 승인 후 개발 연결 검증

사용자가 ‘줄바꿈 수정·현재 주제의 Claude 스토리 생성 전용 연결 운영 반영·정상 Stop/Start 1회·Claude 최대 USD 0.25·공식 견적까지’를 명시적으로 추가 승인했다. 이후 정식 승인 경로로 개발 checkout의 `character_story_only.py`, `windows_live.py` 접점을 반영했다. 이전 거절을 우회하지 않았다.

정확한 주제·참조·선택 해시 및 승인 이후 생성된 작업만 새 요청에 결속한다. 기존 서비스·텍스트 writer·인증·월 예산·미결 요청 검사를 유지하고, 원래 인증·Origin·CSRF 경계 내부에서만 Claude 저장 키를 사용할 수 있다. 전역 복호화나 외부 실행 권한, 영상 submit/check/fetch 권한은 열지 않는다. 기존 정책·요청 저널과 보수 예약은 변경하지 않는다.

정식 모듈 경로의 합성 통합 검사와 정책 해시/만료 loader 검사를 포함해 26 PASS다. 이 검증에는 실제 API·DPAPI 복호화·운영 실행을 사용하지 않았다. 운영 반영과 현재 사용자의 스토리·공식 견적 결과는 후속 항목에 별도로 기록한다.


## 실제 운영·Chrome 실행 결과

명시적 추가 승인 후 코드 `467518fa02e9d07cb017c1712614e4ec2e070e53`의 정확한 6개 파일과 현재 입력 해시에 결속된 private approval을 적용했다. 기존 운영의 Chrome·프로필 맞춤 처리는 보존하고 네 개의 정확한 접점만 추가했다. 준비 중 일반 3줄 문맥이 운영 맞춤 주석과 달라 일치 검사가 멈췄으며, 이 시점에는 운영을 변경하지 않았다. 이후 고유한 승인 접점을 명시적으로 확인해 준비했다.

정상 Stop 종료 코드 0·Start 1회·loopback 18768·Chrome 새 인증을 확인했다. 사용자에게 보이는 실제 Chrome에서 저장된 캐릭터·두 줄 주제·Sonnet 4.6·Kling O3 Standard·30초(6초×5)·모델 소리 켜기·1080p 최종 출력을 복원했다. 편당/일일 한도는 사용자가 선택한 5/10 USD를 유지했으며, 이번 스토리 실행은 별도 USD 0.25 상한으로 제한됐다.

Chrome에서 ‘스토리 자동 생성하기’를 한 번 눌렀다. 줄바꿈이 있는 새 로컬 초안은 생성됐고 실제 Claude 요청도 한 번 진행됐다. 그러나 스토리가 `script_failed`, 예산 예약이 `failed`로 끝났고 검토 가능한 스토리는 저장되지 않았다. 사용량 수신 기록에 따른 환산액은 USD 0.015762이며 실제 공급사 청구 확정액은 아니다. 별도 보수 예약 USD 0.25와 기존 USD 3.65 노출은 유지한다.

현재 증거는 응답 수신·사용량 추출 이후의 envelope/JSON/schema/정확한 장면 길이 검사 중 실패했음을 뒷받침한다. 원응답과 안전한 세부 실패 단계가 보존되지 않아 특정 필드나 정확한 거부 원인은 확정할 수 없다. 30초·5장면·6초와 코드 범위 간 필연적인 충돌은 없으며, 추측으로 모델·키·예산 오류라고 판정하지 않는다.

공식 영상 견적 단계에는 도달하지 않았다. Higgsfield 견적·업로드·영상 생성 요청은 이번 작업에서 0회이며, 임시/Fake 스토리로 단계를 건너뛰지 않았다. 같은 스토리를 자동 또는 수동으로 재전송하지 않았고, 추가 재시작도 하지 않았다. 실패 기록과 새 초안은 보존했다.

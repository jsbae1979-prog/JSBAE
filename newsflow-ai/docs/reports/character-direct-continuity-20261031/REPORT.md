# 캐릭터+주제 30초 직접 영상 연속성 보완

캐릭터/이미지와 주제를 선택하고 30초를 설정하면, 스토리 AI 없이 영상 모델에 15초씩 두 번 요청하는 실행 흐름입니다. 영상 견적과 생성 승인은 기존 절차를 유지합니다. 길이 선택 외에 이어 만들기 체크를 반복하지 않습니다.

첫 구간에는 상황을 시작·발전시키고 행동을 미완으로 이어 두도록 지시합니다. 두 번째 구간에는 같은 캐릭터 정체성과 사용자 주제, 앞 구간의 행동 지시, 전체 30초 중 15–30초라는 위치, 같은 사건을 마무리하는 역할을 함께 전달합니다. 앞 영상의 **실제 마지막 디코딩 프레임**을 시작 이미지로 사용합니다. 기존 0.1초 전 프레임 추출은 직접 제작에서만 마지막 1초를 디코딩해 끝 프레임을 선택하도록 바꿨습니다. 기존 스토리 모드의 추출 동작은 유지합니다. O3는 원본 image_urls를 유지하면서 first_frame_url에 끝 프레임을 넣고, Kling 3.0은 지원되는 image_url 시작 이미지 필드에 끝 프레임을 넣습니다.

상황 전달은 앞 요청의 지시와 마지막 화면에 보이는 상태를 활용합니다. 앞 영상 전체를 분석했다거나 사건 진행을 정확히 관찰했다고 주장하지 않습니다. 캐릭터·소품·장소 유지, 시작 반복 금지, 결말 역할은 견적 전에 고정되며 실제 전송에서 바뀌는 필드는 검증된 시작 프레임뿐입니다. 프레임·원본 클립·상황 문맥 해시를 연결합니다. 문맥 변경, 앞 구간 실패·결과 불명, 견적 상승은 다음 구간 전송을 중단합니다. 자동 유료 재요청은 없습니다.

## 집중 검증

새 연속성 8개와 관련 20개, 합계 **28 PASS / 0 FAIL / 0 ERROR**입니다. TypeScript와 React 빌드도 통과했습니다. 이전 94개 결과는 재사용하며 이번 실행 결과로 합산하지 않습니다. 초기 검사에서 누락된 FFmpeg 테스트 경로와 제거된 UI 상태의 남은 참조를 바로잡았으며 최종 검사는 모두 통과했습니다. 기존 전체 회귀나 Guard 감사는 반복하지 않았습니다.

합성 영상의 끝 프레임만 빨간색으로 만들어 0.1초 전 파란 화면 대신 실제 빨간 마지막 프레임을 전달하는지 검증했습니다. Fake 영상 공급사로 15초·30초 최종 MP4까지 확인했고, 기존 스토리 모드의 15·35·60초 흐름도 영향 범위에서 확인했습니다. 1366×768과 1920×1080 캡처는 합성 데이터입니다. 실제 운영 캡처나 실제 유료 생성 품질 증거가 아닙니다.

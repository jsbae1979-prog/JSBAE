# 샘플12개 권리·교체 준비

**기존 샘플12개 보존 / rightsVerified:false 유지 / 새 제작0·교체0**

기존 file-level 권리 검토와 원본 해시를 그대로 재사용했다. 현재 첨부 원본은
콜라주 추출/확대된 PNG9개와 12초 무음 preview MP4 3개다. 정확한 ChatGPT
생성 대화·원본 다운로드·참조 입력 사용권·상업 설치 패키지 재배포 허락의
추가 증빙은 제공되지 않았다. ChatGPT 출력에 대한 일반 약관만으로
이 파일의 생성자/입력/제3자 권리가 증명되지는 않는다.

`SAMPLE_REMAKE_SPECIFICATIONS.json`은 기존 계획12행을 구체화한다.
각 원본 ID/경로/SHA, 새 별도ID, 자체 도형·벡터 원본 제작 brief,
이미지 해상도/색공간/검수 및 영상 render 규격을 기록했다.
상표·기성 캐릭터·실물 제품 trade dress·인물사진·외부 음원을 사용하지 않는다.
로봇/고양이/드래곤은 독자적 기하 형태로 설계하고 유명 캐릭터 유사성을 검토한다.
독립 이미지와 TOP3 시각 자료는 가상의 교육 예제임을 표시하고 실제 기사·
사실·생성 성공 이력으로 등록하지 않는다.

영상3개는 신규 권리 검토를 마친 자체 이미지로 3장면×4초,
1080×1920/30fps/H.264/yuv420p/faststart, 무음 샘플 preview로 제작하는 안이다.
샘플1개 뉴스·2개 캐릭터 구분을 유지하며 AI 음성 포함 완성 쇼츠라고 표시하지 않는다.
실제 제작·외부 유료 호출·현재 영상 파일 변경은 하지 않았다.

`SAMPLE_CREATION_RECORD_TEMPLATE.json`은 증빙이 아닌 빈 작성 양식이다.
작성자/UTC/정확한 brief 또는 prompt/모델(사용한 경우)/입력 권리·hash/
원본 editable source commit/tool version/export config/출력 hash/
상용 재배포 허락/제3자 검토/검토자·날짜를 모두 채워야 한다.
생성·검토 이전에 rightsVerified를 true로 바꾸지 않는다.

교체는 후속 승인 후 별도 catalog-v2/새 sample ID로만 등록한다.
catalog-v1 원본과 사용자별 복사본/사용자 프로젝트 미디어는 이동·삭제·덮어쓰지 않는다.
숨김 상태는 catalog/id별 유지하고 업데이트 시 사용자가 숨긴 예제를 다시
자동 등록하지 않는다. 새 content hash로 중복을 식별하되 사용자 소유 파일을
원본과 같다는 이유로 삭제하지 않는다. 참조를 자동으로 v2에 재연결하지 않는다.
권리 증빙·시각 검토·포맷/재생 검증·패키징 인수가 완료된 파일만 후속 교체한다.

공개 배포 차단은 **원본에 대한 정확한 증빙 확보 또는 승인된 신규 원본의
실제 제작과 권리 검토**가 있어야 해소된다. 문서 작성만으로 권리 완료가 아니다.

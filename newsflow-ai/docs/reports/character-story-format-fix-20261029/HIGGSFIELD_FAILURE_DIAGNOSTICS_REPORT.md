# Higgsfield 5개 장면 실패 원인 확인 및 최소 수정

확인일: 2026-10-30. 브랜치: `codex/newsflow-bat-distribution-prep`.
운영 반영한 오류 상세 조회 코드: `b8ec27980fd070437d07dcf2ebe5800ad2d4da44`.
이 보고서와 함께 저장한 추가 프롬프트 수정은 개발본에만 적용했다.

## 확정 원인

사용자가 보는 Chrome에서 기존 실패 요청 5건의 상태를 조회했다. **5건 모두 아래 동일한 공급사 오류를 반환했다.**

> The prompt is too long. Shorten it to the limit supported by this model.

한국어 의미: 프롬프트가 너무 길어 모델이 지원하는 길이로 줄여야 한다.

앱이 각 6초 장면에 전체 스토리 계획과 다른 4개 장면 설명까지 반복해서 넣어, 장면별 요청이 3,368~3,471자가 됐다(Python Unicode code point 기준). 기존 Chrome/JavaScript 측정 3,372~3,476과의 차이는 이모지의 UTF-16 단위 계산 차이이며 요청 변경이 아니다. 기존 앱 허용 길이는 4,500자였고 공급사의 실제 길이 제한과 맞지 않았다. 추측하던 길이 문제가 실제 응답으로 확인됐으며, 입력의 분량을 조절하지 못한 **앱 요청 구성 문제**다.

요청한 모델 경로, Standard 모드, 6초, 음성 켜짐, 9:16, 단일 장면 옵션은 공식 Higgsfield 규격의 지원 범위다. 이 항목들이 원인이라고 주장하지 않는다. 확인한 공식 문서와 오류에는 정확한 숫자 상한이 없으므로 다른 공급사의 2,500자 제한을 Higgsfield의 확정 규칙으로 표시하지 않는다.

## 실제 청구·환불

사용자 Chrome의 Higgsfield 요청·거래 내역을 기존 앱 요청과 1:1 대조했다. 요청 상세의 사용료는 장면당 US$0.672, 총 US$3.360이었다. 대응 Usage 5건과 Refund 5건이 모두 Completed로 표시됐으며, 모델별 사용량의 O3 순청구액은 **US$0.00**이었다. 거래 행의 두 자리 반올림과 요청 상세 금액을 구분했다. 이전 다른 모델의 성공한 영상 사용료와 혼동하지 않았다.

환불은 실제 계정 거래 화면에서 확인했으며 단순 오류 상태나 일반 환불 정책으로 추정한 것이 아니다. 은행·카드의 별도 청구서 검증을 수행했다고 주장하지 않는다.

## 승인된 운영 반영과 Chrome 결과

- 기존 정상 BAT Stop 종료 코드 0, Start 1회. 오류 상세 관련 9개 파일을 백업 후 반영했다.
- 새 인증으로 자동 열린 Chrome에서 기존 작업을 선택하고 `실패 상세 확인`을 실행했다.
- 기존 요청의 GET 조회 5건만 수행했다. 새 생성·재시도·업로드·견적·다운로드는 수행하지 않았다.
- 07:05:04~07:05:07 KST에 5개 오류가 저장·표시됐다. 기존 장면 상태는 모두 failed로 유지됐다.
- 일부 기본 프로세스 조회는 실행 환경 제한으로 보이지 않았으나, 동일 Start의 Python 프로세스와 인증 전 HTTP 403, 정상 인증된 Chrome GUI로 서버 준비를 확인했다. Start를 반복하지 않았다.

## 프롬프트 최소 수정

개발본의 새 제작 준비는 **현재 장면의 행동·캐릭터 참조·스타일·음성 지시와 간결한 공통 상황**만 조합한다. 전체 5장면과 결말 설명을 모든 클립에 반복하지 않는다. 저장된 스토리는 줄이거나 덮어쓰지 않으며 Claude를 다시 호출하지 않는다.

앱의 보수적 요청 한도는 2,000자로 설정했다. 문자열을 중간에서 잘라 의미를 손상하지 않는다. 한도를 넘으면 참조 업로드·견적·유료 제출 전에 안내한다. 기존 긴 요청의 재시도 견적·제출도 전송 전에 차단하며, 기존 실패 payload·견적·승인에 새 프롬프트를 끼워 넣지 않는다. 수정된 요청은 기존 스토리를 이용한 **새 영상 작업과 새 견적**에서만 사용한다.

기존 증거 복사본에서 새 요청을 계산만 한 결과(추가 API 호출 없음):

| 장면 | 기존 요청 글자 수 | 수정 요청 글자 수 | 장면 길이 |
| --- | --- | --- | --- |
| 1 | 3,414 | 1,159 | 6초 |
| 2 | 3,368 | 1,113 | 6초 |
| 3 | 3,401 | 1,146 | 6초 |
| 4 | 3,425 | 1,170 | 6초 |
| 5 | 3,471 | 1,216 | 6초 |

복사본 해시 및 메모리상의 기존 작업은 계산 전후 동일하다.

이 추가 수정은 운영에 아직 적용하지 않았다. 이번에 승인한 Stop·Start 1회는 오류 조회 기능 반영에 사용했다. 추가 운영 재시작이나 유료 생성 승인 없이 결과를 성공 처리하지 않는다.

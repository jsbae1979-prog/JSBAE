## 실행 중 확인 사항

초기 프로세스·포트 목록 조회가 불완전해 서버가 없다고 판단했으나, 직접 loopback 연결과 운영 Python 실행 계보로 서버가 실행 중임을 확인해 정정했다. 정상 Stop 직후 Windows 프로세스 객체가 잠시 남아 준비 스크립트의 확인이 중단됐지만 Stop 자체는 코드 0으로 완료됐다. 추가 Stop이나 강제 종료 없이 종료 기록·프로세스 소멸·포트 해제를 확인했다. Start 직후 첫 보존 검사는 시작 기록이 생기기 전이어서 미완료였고, READY 기록 후 같은 검사를 완료했다. Start 재실행은 없었다.

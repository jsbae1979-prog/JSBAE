# 캐릭터 최종 합성: 자막·추가 음성 제거

2026-10-29. 사용자 추가 지시에 따라 개발본을 최소 수정했다. 현재 운영 앱에는 아직 반영하지 않았으며 추가 재시작도 하지 않았다.

- 캐릭터 제작실의 FFmpeg 최종 합성에서 장면 설명 자막과 AI 문구를 굽는 처리를 제거했다. 훅·엔딩·폰트·ASS 파일도 만들지 않는다.
- 새 TTS·나레이션·외부 음성·효과음을 추가하지 않는다. 모델에서 생성된 장면 영상의 원래 소리를 유지하고, 원래 무음인 영상은 무음으로 연결한다.
- 현재 제작실은 정규화한 장면을 연결한 뒤 영상·오디오 스트림을 그대로 최종 파일에 담는다. 구형 30초 제작 경로도 새 음원을 읽지 않고 실제 원본 오디오만 해당 장면 시간에 유지한다.
- 합성 검토창에 ‘자막이나 새 음성·나레이션을 추가하지 않고 원래 소리만 유지’한다고 안내한다. AI 생성 사실 확인과 게시 플랫폼의 표시 검토는 별도로 유지한다.
- 기존 완료 영상은 재합성하거나 덮어쓰지 않는다. 공급사 원본에 이미 들어 있는 글자·음성까지 제거하는 기능은 아니며, 이번에 새 영상을 생성하지도 않았다.

## 집중 검증

- 제작실 명령 계약 4개와 실제 로컬 합성·오디오 누락 보호 3개: 7 PASS.
- 구형 합성 명령 계약 5개와 실제 혼합 오디오·무음 합성 2개: 7 PASS. 실제 혼합 영상의 5초·25초는 무음이고 15초에는 원본 합성 톤이 남는 것을 PCM으로 확인했다.
- TypeScript·Vite 빌드 PASS. 첫 매체 검사에서는 테스트 PATH에 FFmpeg가 없어 3건 실패했고, 기존 검증된 FFmpeg·FFprobe 경로를 명시한 뒤 해당 범위만 재검증해 통과했다. 제품이나 보안 정책을 바꿔 통과시킨 것이 아니다.
- 실제 사용자 영상·운영 DB·키·미디어·백업·서버 프로세스를 변경하지 않았다. 유료 API·SNS 호출은 0회다.

## 운영 반영

앞서 승인된 정상 Stop·Start 1회는 길이·화질·내 캐릭터 저장 반영에 이미 사용했다. 이 추가 Python 합성 변경은 별도 정상 재시작이 필요하다. 운영에는 기존 합성 코드가 남아 있으므로 반영 전 최종 합성을 실행하지 않는다.

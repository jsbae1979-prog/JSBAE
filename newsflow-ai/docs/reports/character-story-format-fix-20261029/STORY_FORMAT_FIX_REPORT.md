# 스토리 응답 형식 최소 보완 및 O3 견적 재진행

2026-10-29. 사용자가 필요한 운영 반영·정상 Stop/Start 1회와 기존 캐릭터/주제 재진행, 기존 스토리 사용분 포함 USD 10 한도를 승인했다. 영상 생성은 견적 확인 후 별도 승인이다.

## 확인된 원인과 관측 한계

이전 실제 요청은 사용량이 포함된 Claude 응답을 받았지만 로컬 형식 검사에서 실패했다. 과거 원응답과 세부 실패 단계가 저장되지 않아 그 요청의 특정 거부 필드는 확정할 수 없다. 정확한 5×6초, 장면 순서, 영어 행동문 등과 일반 wire schema 간 검증 간극 및 모든 실패를 같은 메시지로 처리하는 진단 누락은 합성 검사로 재현했다. 이를 과거 실제 실패 필드라고 단정하지 않는다.

## 최소 수정

- 요청 schema에 선택된 장면 길이 enum, 기존 영어 행동문 조건의 간단한 pattern, 비어 있는 narration enum을 반영했다. Claude가 지원하지 않는 minItems>1은 추가하지 않았다. 정확한 장면 수·총길이·순서는 로컬 검증을 유지한다.
- 종료 사유, envelope, JSON, schema, timing 실패를 구분하고 필드 위치와 정해진 오류 유형만 기록한다. 원문이나 예외 input/prose, 키·토큰을 일반 오류·로그·공개 read model에 넣지 않는다.
- 파싱된 스토리 JSON 후보와 사용량은 사용자 데이터의 해당 작업 폴더에 불변 private 파일로 보존하고 SHA-256을 기록한다. 실패·성공·이전 시도 이력과 원래 참조 이미지를 보존한다. 이 private 응답 파일은 GitHub나 GUI의 일반 자료 응답에 포함하지 않는다.
- 알려진 응답 실패만 기존 서비스의 명시적 재생성 동작으로 이어진다. 사용자 클릭 없이 자동 재요청하지 않으며, 결과 불명·진행 중·성공 요청은 재전송하지 않는다.
- 새 승인 정책은 현재 작업·주제·참조·O3 Standard/30초/음성 설정에 결속한다. 이전 trial의 스토리 예약 USD 0.50과 이전 스토리 승인 예약 USD 0.25를 보존해 기존 보수 노출 USD 0.75를 포함하고, 새 요청당 최대 USD 0.25와 스토리 총 USD 10을 적용한다. 기존 영상 노출 USD 3.15는 별도 보존하며 영상 생성 권한은 열지 않는다.
- 기존 인증·CSRF·Origin·DPAPI·월 예산·비용 기록과 text-only Claude writer를 재사용한다. 참조 PNG는 Claude로 보내지 않는다. FFmpeg의 자막·추가 음성 없음 정책은 변경하지 않는다.

## 집중 검증

변경 영향 범위 통합 84 PASS, TypeScript PASS, Vite 빌드 PASS. 실제 공급사·실제 키 복호화·운영 앱은 이 검사에 사용하지 않았다. 기존 전체 회귀·Guard 감사·디자인 검증은 반복하지 않았다.

개발 중 하위 에이전트의 별도 checkout 쓰기는 자동 승인 검토가 권한 맥락 부족으로 거절했다. 재시도/우회하지 않았고, 현재 사용자 원문 승인 범위를 가진 root가 동일 소스 변경을 정식 승인 도구로 허용받아 반영했다. 운영 결과는 아래 후속 절에 별도로 기록한다.

## 2026-10-30 실제 Chrome 재진행 및 원인 확정

승인된 정상 Stop/Start 1회를 사용했다. Stop 0, 운영 9파일 반영, React 정상 인증 후 사용자가 보는 Chrome에서 저장된 같은 작업을 명시적으로 다시 요청했다. Claude 요청은 1회, 영상 요청은 0회다.

이번 attempt 2는 정상 종료된 응답(end_turn)이었고 정확히 5×6초, 빈 narration이었다. 실제 로컬 검사 실패는 plan.situation/contrast/punchline의 183/164/186자가 기존150자를 넘고, sfx 5개 중62/64/66/88자가 기존60자를 넘은 7건이다. 이전 attempt 1의 특정 실패 필드는 여전히 미확정이다. 이번 응답은 private 파일로 보존했으며 GitHub에는 내용·이미지·주소를 올리지 않는다.

추가 스토리 요청의 보고 사용량 비용 추정은 USD0.016092(공급사 확정 청구액 아님), 과거 보수 예약 포함 누계는 USD1.00이다. 응답을 버리고 반복 호출하지 않았다. 기존169기사/47테이블, 보호26파일 및 ACL, 기존 제작파일42개, 원본DB/백업A·B와 과거 비용행은 보존됐다. 새 API 사용행1개, 해당 작업의 실패·응답 기록만 변경됐다.

## 추가 수정: 응답을 훼손하지 않는 로컬 복구

Studio 전용 계획문 최대200자, 효과음 설명 최대100자로 최소 조정했다. 과거 전용 Plan/Scene 계약과 행동문300자·자막·타이밍·상황극 조건은 유지한다. 이번 저장 응답은 자르거나 바꾸지 않고 새 계약을 통과한다. GUI의 ‘저장된 스토리 복구 · 추가 비용 없음’은 명시적인 로컬 동작으로 완결된 실패 응답의 해시/작업/장면수/시간/원본참조를 다시 검사한 뒤 script_review로 옮긴다. 기존 실패 및 공급사 비용 기록을 성공/환불로 덮어쓰지 않고 복구 이력을 별도 보존한다. 불완전 응답·결과불명·변조·이미 성공한 작업은 복구하지 않는다.

## 사용자 후속 지시: 프로그램 전체 실행별 한도

사용자가 프로그램 전체 AI 제작의 일일·월간·누적 제한 제거를 명시했다. 과거 제한 설정과 비용·사용량·예약 이력은 보존하되 새 요청을 차단하는 누적 조건에서 제외했다. 현재 실행의 비용·토큰·입력 글자 수·영상 묶음 견적만 해당 실행 한도와 비교한다. 캐릭터5장면 생성은 한 번의 제작이며 별도 승인한 장면 재시도는 별도 실행 견적만 비교한다. 총액은 기록용으로 계속 누적된다.

Claude/OpenAI 텍스트의 1회 USD/토큰, ElevenLabs 1회 입력 글자 수, Higgsfield 영상의 1회 견적을 설정한다. OpenAI 이미지의 기존1이미지/명시승인 경계는 유지하고 미확정 단가를 임의 USD 금액으로 표시하지 않는다. 확인되지 않은 영상 가격도 0원으로 간주하지 않는다. 명시적인 실행 한도가 없는 기존 설정은 새 한도를 입력해야 하며 과거 큰 월 한도를 1회 한도로 자동 전용하지 않는다.

견적 조회 자체는 유료 생성이 아니므로 1회 한도 초과 여부를 조회 후 표시하고, 실제 제출 시에 해당 한도를 적용한다. 인증·CSRF·Origin·DPAPI·승인·진행중/결과불명 재전송 차단은 유지한다. 누적 한도 제거가 영상 생성 승인이나 전역 외부 실행 허용을 뜻하지 않는다.

추가 변경의 운영 반영에는 새 Python 프로세스가 필요하다. 이번에 승인된1회 재시작은 이미 사용했으므로 추가 승인을 받기 전에는 운영본을 다시 재시작하지 않는다. 현재 운영은5f945e7이며 후속복구/한도 변경은 개발본 준비 상태다. 다음 운영반영 후 Chrome에서 보관 응답 복구→O3 Standard/30초/음성 포함 공식견적까지만 진행하며 영상 생성은 별도 승인을 기다린다.

최종 변경 검사: 복구/실행별 한도/승인 연결 39 PASS, 캐릭터 예산·견적 10 PASS, 스토리 응답 길이/기존 계약 통합 38 PASS, Node 사용자 흐름 11 PASS, TypeScript/Vite PASS. 원래84 PASS는 재사용하며 신규 수치에 합산하지 않는다.
